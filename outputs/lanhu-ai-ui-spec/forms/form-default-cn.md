# Form 默认尺寸（中文）

来源：`Form/default-cn`

## 规范元数据

| 字段 | 值 |
| --- | --- |
| 文档类型 | 表单规范 |
| 蓝湖画板 | `Form/default-cn` |
| 画板数量 | `1` |
| 画板场景 | `5` 条；计入全库 183 条场景 |
| 来源判定 | 规范表中未特别注明的可见数值为“蓝湖标注”；带“画板实测”字样的值为“画板实测”；实现、使用、提交、布局和异步规则为“研发补充” |
| 绘制基准 | 蓝湖 Web `@1x`；“画板实测约”表示按画板像素测量的近似值 |
| 通用视觉基线 | [组件尺寸与样式基线](../foundations/component-sizing.md)；本文件显式值覆盖通用值 |
| 图标资产清单 | [组件图标资产清单](../assets/icons/manifest.md)；本文件“图标资产”章节决定具体使用与替换边界 |

## 尺寸与样式

| 项目 | 规范 |
| --- | --- |
| 控件高度 | `32px` |
| 主控件示例宽度 | 画板实测约 `392px` |
| 行内输入示例宽度 | 画板实测约 `144px` |
| 字号 / 行高 | `14px / 22px` |
| 标签与控件水平间距 | 画板常用 `12px` |
| 字段纵向间距 | 画板实测约 `16px` |
| 必填标记 | Danger 色 `*`，紧邻标签 |
| 文本域 | 与主控件等宽，高度按行数扩展 |
| 典型表单标签 / 控件 | 标签区 `68px`；控件 `392px`；表单内容总宽 `460px` |
| 对齐表单标签 / 控件 | 左、右对齐标签区 `78px`；控件 `382px`；顶部对齐控件 `460px` |
| 行内字段 | 审批人标签 / 输入 `54px / 146px`；活动区域标签 / 输入 `68px / 132px` |
| 行内间距 / 按钮 | 字段组间距 `24px`；查询、重置按钮均为 `60px × 32px` |
| 日期时间组合 | 同一控件行内使用日期框 + `-` + 时间框；两端等宽，组合总宽继承当前控件宽度 |
| 多行输入 | `52px` 高；上下内边距保持占位文字位于首行 |

默认尺寸中文表单用于后台常规编辑、筛选和配置页面。宽度可随栅格调整，但同一列控件左、右边界应对齐。

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |

| 操作区 | 主按钮 + 次按钮 | 与字段控件起始边对齐 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-FORM-DEFAULT-CN-01` | 典型表单 | 活动名称、活动区域、活动时间、即时配送、活动性质、特殊资源、活动形式、创建/取消 | 综合展示 Input、Select/日期、Switch、Checkbox、Radio、Textarea 和按钮在标准纵向表单中的组合 |
| `SCN-FORM-DEFAULT-CN-02` | 行内表单 | 审批人、活动区域、查询、重置 | 垂直空间有限且字段较少时使用；所有标签、控件和按钮保持 `32px` 高度节奏 |
| `SCN-FORM-DEFAULT-CN-03` | 标签左对齐 | 标签从统一左边界开始，控件从统一输入线开始 | 适合标签长度接近、希望快速扫描标签起点的表单 |
| `SCN-FORM-DEFAULT-CN-04` | 标签右对齐 | 标签靠近对应控件，必填星号跟随标签 | 字段对应关系最清晰，适合常规后台录入 |
| `SCN-FORM-DEFAULT-CN-05` | 标签顶部对齐 | 标签在控件上方，控件纵向排列 | 适合窄屏、长标签或需要控件占满整行的页面 |

## 场景精确差异

- 典型表单的活动名称、活动区域、活动时间均为普通 Input，不显示 Select 箭头或日期图标；这是与英文典型表单的明确差异。
- 行内表单第二个输入框为 `132px`，不是第一个输入框的 `146px`；查询和重置按钮各 `60px`。
- 标签左对齐场景显示顶部三段“选项”切换；标签必填星号位于文字后。标签右对齐时星号位于文字前。
- 顶部对齐场景的标签、输入、日期时间、Switch、Checkbox、Radio、Textarea 和按钮全部按单列 `460px` 输入线组织。
- 参考画板可能从字段中部开始，不得把裁切缺失误解为真实页面应删除名称标签或分段选项；AI 生成完整页面时必须按完整表单结构输出。

## AI 还原约束

- 必须使用组件库 Form、FormItem、Input、Select、DatePicker、TimePicker、Switch、Checkbox、Radio、Textarea、Button 组合，不得用原生控件替代。
- 主色按钮使用 `#FF6014`，危险星号使用 `#F53F3F`，默认边框使用 `#DCDCDC`，占位文字使用 `#BFBFBF`。
- Select 下拉箭头、日期日历图标、时间图标直接映射组件库对应图标；如业务替换图标，只能使用[组件图标资产清单](../assets/icons/manifest.md)中的等义资产。
- 同一行所有控件必须等高；页面宽度不足时改为单列，禁止横向溢出、压缩标签或截断操作按钮。

## 布局规则

- 典型表单：标签左侧、控件右侧，操作按钮与控件起始线对齐。
- 行内表单：短标签、输入框和查询/重置按钮放在同一行，控件保持 `32px` 高。
- 标签支持左对齐、右对齐和顶部对齐；同一分组只使用一种。
- 画板覆盖分段选择、输入、Select、日期/时间、Switch、Checkbox、Radio、Textarea 和按钮。
- 标签、控件、帮助文案和错误文案保持稳定的垂直节奏。
- 必填标识与字段标签一起展示；不要把必填信息仅放入占位文案。
- 错误提示紧邻对应控件，避免统一堆放到页面顶部。

## 提交规则

- 提交前校验所有必填项。
- 首个错误字段应获得焦点或清晰定位。
- 异步提交期间，提交按钮进入加载或禁用状态，防止重复提交。
