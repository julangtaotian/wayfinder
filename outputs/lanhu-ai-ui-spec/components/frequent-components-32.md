## 尺寸基线

本画板统一了后台高频操作控件的 32px 尺寸档，适用于筛选栏、表格工具栏和紧凑型编辑区。

| 项目 | 规范 |
| --- | --- |
| 统一控件高度 | `32px` |
| 字号 / 行高 | `14px / 22px` |
| 默认圆角 | `2px` |
| 默认边框 | `1px solid @component-border` |
| 控件横向间距 | 画板常用 `8px` |

## 使用规则

- 同一操作区内优先使用同一尺寸档，避免 32px 与其他高度混排。
- 紧凑尺寸不应降低文字可读性或点击热区；图标操作需保留提示文字。
- 有表单校验、长文本或复杂辅助说明时，使用默认或大尺寸表单规范。
