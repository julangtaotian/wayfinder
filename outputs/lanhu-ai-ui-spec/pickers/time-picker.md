## 尺寸与样式

| 项目 | 画板规格 |
| --- | --- |
| 单值输入框 | 画板实测约 `216px × 32px` |
| 固定时间列表面板 | 画板实测约 `240px` 宽 |
| 任意时间滚轮面板 | 画板实测约 `180px` 宽 |
| 范围输入框 | 画板实测约 `328px × 32px` |
| 范围滚轮面板 | 画板实测约 `350px` 宽 |
| 列表项 | `32px` 高 |
| 操作区 | 底部“取消 / 确定”，默认 `32px` 高按钮文字区 |

固定时间点以单列列表展示，画板示例按 `15` 分钟递增。任意时间点采用时、分、秒三列滚轮；当前行加深并用上下分隔线定位。范围选择并列展示开始时间和结束时间。

| 场景 | 面板可见外尺寸 | 内部结构 | 来源 |
| --- | --- | --- | --- |
| 固定时间点 | 约 `240px × 176px`；含外边框时允许 `±2px` | 5 个可见行，每行 `32px`，列表可见区 `160px` | 画板实测 |
| 任意时间点 | 约 `180px × 225px`；高度允许 `±2px` | 时/分/秒三列，每列约 `59px`；底部操作区 `32px` | 画板实测 |

任意时间滚轮默认以 `18 : 40 : 00` 为中心选中行：小时列可见 `16～20`，分钟列可见 `38～42`，秒列以 `00` 为中心；范围场景两端都使用相同的初始中心行。当前行文字为主要文字色并提高字重，非当前行使用次要文字色。

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 触发器 | 时间值/占位 → 时钟/清空图标 | 遵守同尺寸输入控件视觉 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 时间面板 | 小时/分钟/秒列或固定时间单列 | 列高、选项行高和滚动遮罩按尺寸表 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 选项 | 时间文本 → 可选选中勾选 | Hover、Selected、Disabled 状态可区分 | 蓝湖标注/画板实测；未标注项按研发补充 |

| 状态 | 触发条件 | 可见变化 | 恢复方式 | 来源 |

| Hover / Selected / Disabled | 悬停、已选或禁用时间 | 背景、文字和勾选按状态变化 | 移出、改选或解除禁用后恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |

| 场景 ID | 场景 | 画板展示 | 说明 |

| `SCN-TIME-PICKER-03` | 任意时间范围 | 开始时间、结束时间两组三列滚轮 | 触发器显示 `开始时间 / 至 / 结束时间`；两端初始中心行为 `18 : 40 : 00`，底部显示取消/确定 |

## 使用规则

- 明确采用 24 小时制或 12 小时制，避免同时混用。
- 时间范围需要校验结束时间不早于开始时间。
- 当时间仅作为展示条件时，可使用日期时间选择器的时间部分，避免重复控件。
