## 尺寸与样式

| 项目 | Default | Small |
| --- | --- | --- |
| 页码 / 翻页按钮 | `32px × 32px` | `24px × 24px` |
| 每页条数选择器 | `128px × 32px` | 画板实测约 `100px × 24px` |
| 跳页输入框 | `56px × 32px` | 画板实测约 `40px × 24px` |
| 字号 | `14px` | 画板实测约 `12px` |

画板同时给出无背景和带背景两种样式。带背景页码使用中性浅背景，当前页使用品牌色填充和白字；无背景当前页使用品牌色文字。省略号用于折叠中间页码。

以下数量是单个规范场景内部必须完整还原的组件实例数，不得只保留其中一个代表性分页：

| 样式区段 | 实例数量 | 从上到下的固定组合 | 页码序列与颜色 |

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 信息区 | 可选总条数 → 每页数量选择器 | 与页码区同高并垂直居中 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 页码区 | 上一页 → 页码/省略号 → 下一页 | 相邻项间距一致；当前页持续强调 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 跳转区 | “前往”文字 + 输入框 + “页” | 输入框遵守同尺寸 Input 规范 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 画板场景

画板对无背景默认样式、带背景样式和 Small 模式分别展示相同的组合能力：

| 场景 ID | 组合 | 包含区域 | 适用场景 |
| --- | --- | --- | --- |
| `SCN-PAGINATION-01` | 基础分页 | 总条数 + 页码 | 用户需要知道结果总量 |
| `SCN-PAGINATION-02` | 条数选择 | 每页条数 + 页码 | 总量已在其他位置展示 |
| `SCN-PAGINATION-03` | 完整信息 | 总条数 + 每页条数 + 页码 | 后台列表的常规默认组合；不包含跳页输入 |
| `SCN-PAGINATION-04` | 快速跳页 | 页码 + 跳页输入 | 页数很多，需要直接定位 |
| `SCN-PAGINATION-05` | 总量与跳页 | 总条数 + 页码 + 跳页输入 | 需要总量但不允许修改每页条数 |
| `SCN-PAGINATION-06` | 条数与跳页 | 每页条数 + 页码 + 跳页输入 | 允许调整密度并快速定位 |
| `SCN-PAGINATION-07` | 全部能力 | 总条数 + 每页条数 + 页码 + 跳页输入 | 数据量大且用户操作频繁 |

| 场景 ID | 样式场景 | 画板差异 |
| --- | --- | --- |
| `SCN-PAGINATION-08` | 默认样式 | 必须一次展示上述 `7` 行完整组合；页码无独立背景，当前页仅使用品牌色文字 |
| `SCN-PAGINATION-09` | 带背景 | 必须一次展示上述 `7` 行完整组合；每个页码具有浅色方形背景，当前页品牌色填充 |
| `SCN-PAGINATION-10` | Small 模式 | 必须一次展示 `14` 行：先展示 `7` 行无背景组合，再展示 `7` 行带背景组合；全部区域缩至 `24px` 高 |

## 使用规则

- 翻页后将焦点置于内容区起始位置，确保键盘和读屏用户知道内容已更新。
- 页码过多时使用省略策略，当前页附近优先保留。
- 每页条数改变后应重新计算页码并回到合理页位。
