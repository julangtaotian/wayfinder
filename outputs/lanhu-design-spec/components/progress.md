# Progress 进度条

来源：`Progress进度条`

## 规范元数据

| 字段 | 值 |
| --- | --- |
| 文档类型 | 组件规范 |
| 蓝湖画板 | `Progress进度条` |
| 画板数量 | `1` |
| 画板场景 | `5` 条；计入全库 183 条场景 |
| 还原状态 | 蓝湖可见内容已记录；已通过双组件库隔离还原和全量三方视觉确认 |
| 来源判定 | 规范表中未特别注明的可见数值为“蓝湖标注”；带“画板实测”字样的值为“画板实测”；实现、使用、提交、布局和异步规则为“研发补充” |
| 测量基准 | 蓝湖 Web `@1x`；“画板实测约”项目按 `±2px` 容差验证 |
| 通用视觉基线 | [组件尺寸与样式基线](../foundations/component-sizing.md)；本文件显式值覆盖通用值 |
| 图标资产清单 | [组件图标资产清单](../assets/icons/manifest.md)；本文件“图标资产”章节决定具体使用与替换边界 |

## 尺寸与样式

| 类型 | 画板规格 |
| --- | --- |
| 细线进度条 | 宽 `300px`，轨道厚度画板实测约 `6px` |
| 内嵌文字进度条 | 宽 `300px`，高度画板实测约 `24px` |
| 环形进度条 | `120px × 120px`，线宽画板实测约 `6px` |
| 百分比文字 | `14px`；内嵌时使用白字 |

## 状态与颜色

| 状态 | 颜色 |
| --- | --- |
| 进行中 | Brand 常规色 |
| 成功 | Success 常规色 |
| 警告 | Warning 色 |
| 异常 | Danger 常规色 |
| 未完成轨道 | 中性浅背景 |

画板覆盖线性、内嵌百分比、自定义颜色、环形以及自定义文案/图标。完成、警告、异常状态在末端或圆心显示对应状态图标。

### 蓝湖画板可见实例

| 场景 | 实例数量与顺序 | 数值、文案和颜色 |
| --- | --- | --- |
| 直线进度条 | 从上到下 `5` 条 | `50%` 品牌橙、`Full` 品牌橙、成功满进度、警告满进度、异常 `50%`；状态图标位于轨道右侧 |
| 内嵌百分比 | 从上到下 `4` 条 | 品牌橙 `50%`、成功绿 `100%`、警告黄 `50%`、异常红 `50%`；百分比为白字并位于已完成区域右侧 |
| 自定义颜色 | 从上到下 `3` 条进度条，之后是 `2` 个并排图标按钮 | 三条均为 `20%`，颜色依次为 `#FF6014 / #999999 / #E6A23C`；按钮尺寸 `56px × 40px`，右侧按钮使用品牌色边框和图标 |
| 环形进度条 | 从左到右 `5` 个 `120px × 120px` 圆环 | 空轨道、品牌橙 `25%`、成功满环、警告满环、异常满环；后三项在圆心显示对应状态图标 |
| 自定义内容 | 先显示 `2` 条线性进度，再显示 `2` 个环形进度 | 尾部文案 `content`、异常红内嵌 `50%`、成功满环及大号成功图标、品牌橙 `80%` 环和圆心两行文案 `80% / Progressing` |

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 轨道 | 线性轨道或环形底轨 | 背景色和厚度按类型/尺寸 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 进度层 | 覆盖轨道的状态色长度/弧度 | 数值决定比例，状态决定颜色 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 信息区 | 百分比、状态文字或状态图标 | 位于轨道尾部、内部或圆心 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 必要交互 UI 状态

| 状态 | 触发条件 | 可见变化 | 恢复方式 | 来源 |
| --- | --- | --- | --- | --- |
| Progressing | 进度未完成 | 显示当前比例和品牌/自定义色 | 数值变化时平滑更新 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Success / Warning / Exception | 进入完成或异常状态 | 进度色、文字和状态图标同步切换 | 状态回到进行中后恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 图标资产

| 图标语义 | 本地资产 | 显示尺寸 | 颜色 | 适用状态 | 替换边界 | 来源 |
| --- | --- | --- | --- | --- | --- | --- |
| 成功 / 警告 / 异常 | 蓝湖未提供独立资产 | `14px～16px`；大状态图标按画板尺寸 | 成功/警告/错误功能色 | Success / Warning / Exception | 语义和颜色必须同时一致，不能只替换颜色 | 画板实测 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-PROGRESS-01` | 直线进度条 | 50%、Full、成功、警告、异常，共 `5` 条 | 百分比或状态图标位于轨道右侧；Full 表示已完成 |
| `SCN-PROGRESS-02` | 进度条内显示百分比 | 50%、100%、警告 50%、异常 50%，共 `4` 条 | 轨道加粗并把白色百分比放入已完成区，空间不足时改为外置 |
| `SCN-PROGRESS-03` | 自定义进度条颜色 | 三条 `20%` 进度依次使用品牌橙、灰、警告黄，底部展示两个搜索图标按钮 | 只用于非标准业务分类；成功/警告/异常仍优先使用语义色 |
| `SCN-PROGRESS-04` | 环形进度条 | 空轨道、25%、成功满环、警告满环、异常满环，共 `5` 个 | 百分比或状态图标居中，圆环颜色表达状态 |
| `SCN-PROGRESS-05` | 自定义内容 | 自定义尾部文字 `content`、异常红内嵌 `50%`、成功大图标、`80% + Progressing` | 内容可替换，但必须保留清晰的进度值或结果状态 |

## 使用规则

- 确定进度需要展示已完成比例或清晰的百分比文本。
- 不确定进度使用加载样式，不伪造具体百分比。
- 完成和失败状态应与任务结果文案同步出现。
