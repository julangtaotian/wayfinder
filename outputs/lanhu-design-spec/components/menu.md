## 状态样式

| 状态 | 表现 |
| --- | --- |
| 默认 | 主文字色、透明背景 |
| Hover | 浅品牌或中性 Hover 背景 |
| 选中 | 品牌色文字；顶栏增加底部线 |
| 禁用 | 禁用文字色，不响应点击 |

画板覆盖顶栏基础菜单、顶栏 Dropdown、侧栏分组、二级菜单、图标、选中和禁用。

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 菜单容器 | 顶栏或侧栏菜单区域 | 背景、宽高和分隔关系按菜单类型 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 菜单项 | 可选前置图标 → 标签 → 可选展开箭头 | 图标、文字和箭头垂直居中；层级通过缩进表达 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 子菜单 | 紧邻父项展开 | 保持 Hover 路径连续，层级浮层/内嵌结构按画板场景 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 必要交互 UI 状态

| 状态 | 触发条件 | 可见变化 | 恢复方式 | 来源 |
| --- | --- | --- | --- | --- |
| Default / Hover / Selected | 未交互 / 悬停 / 当前路由或值 | 背景、文字、图标按状态表变化；Selected 保持持续强调 | 移出或路由变化后恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Expanded | 点击或悬停可展开父项 | 箭头旋转或改向，子菜单出现 | 关闭后隐藏子菜单 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Disabled | 菜单项禁用 | 文字和图标使用禁用色且无 Hover/Selected 反馈 | 解除禁用恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-MENU-01` | 顶栏－基础用法 | Processing Center、Workspace、Info、Orders | 当前项使用品牌色文字和底部指示线；禁用项降低对比度 |
| `SCN-MENU-02` | 顶栏－Dropdown | 一级下拉菜单 + 向侧边展开的二级菜单 | 父项用箭头表示可展开；子菜单与父菜单保持相邻，Hover 路径不能意外中断 |
| `SCN-MENU-03` | 侧栏－基础用法 | 导航项、Group one/two、嵌套项、选中项、禁用项 | 分组标题只作结构说明；二级项缩进；当前导航使用品牌色；禁用项不可点击 |

## 使用规则

- 当前选中项应与页面内容建立一一对应关系。
- 禁用项需要保留可读性，但不响应点击。
- 菜单项文字宜使用动宾或名词短语，避免同一层级混合不同命名方式。
