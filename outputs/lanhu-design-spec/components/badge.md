## 尺寸与样式

| 类型 | 尺寸与样式 |
| --- | --- |
| 数字徽章 | 最小 `20px × 20px`，圆角 `10px` |
| 小红点 | `6px × 6px`，正圆 |
| 文本徽章 | 高度 `20px`，左右内边距按文案扩展 |
| 字号 | 画板实测约 `12px`，白色文字 |

数字徽章覆盖单位数、多位数和溢出状态；画板示例使用 `9+`、`99+`。自定义文本示例为 `New`、`Hot`。语义色示例包括 Danger 红、Brand 橙和 Warning 黄。

### 场景组合精确值

| 项目 | 画板规格 | 来源 |
| --- | --- | --- |
| 语义色 | Danger `#F53F3F`；Brand `#FF6014`；Warning `#E6A23C` | 蓝湖功能色 + 画板实测 |
| 数字/文本徽章内部 | 高 `20px`；最小宽 `20px`；左右内边距 `6px`；字号 `12px`；行高 `18px`；白字 | 画板实测 |
| 徽章轮廓 | `1px` 白色描边，用于与宿主背景分离 | 画板实测 |
| 同行宿主间距 | `12px`；画板按钮宿主高 `32px` | 画板实测 |
| 右上角锚点 | 徽章中心贴近宿主右上角；`20px` 高徽章的垂直中心与宿主上边缘对齐，向外叠加且不参与宿主布局 | 画板实测 |

场景初始组合固定如下：

- 基础用法依次展示 `comments / 12 / Danger`、`replies / 3 / Danger`、`comments / 1 / Brand`、`replies / 2 / Warning`。
- 不同语义色使用三个 `comments / 12`，依次为 Danger、Brand、Warning。
- 最大值使用 `comments / 99+` 与 `replies / 9+`；自定义内容使用 `comments / New` 与 `replies / Hot`。
- 小红点依次附着在 `32px` 图标按钮、文本 `query` 和邮件图标宿主上。

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 宿主内容 | 文字、按钮或图标；先渲染宿主，再叠加徽章 | 宿主尺寸不因徽章改变 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 徽章标记 | 数字/文本徽章或小红点，定位在宿主右上侧 | 圆形或胶囊形；状态色表达提醒等级 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-BADGE-01` | 基础用法 | `12`、`3`、`1`、`2` 等数字徽章 | 附着在 comments、replies 等宿主右上角，不占用宿主正常布局 |
| `SCN-BADGE-02` | 不同语义色 | 红、品牌橙、警告黄 | 颜色用于区分消息级别或业务类别，同一含义保持固定映射 |
| `SCN-BADGE-03` | 最大值 | `99+`、`9+` | 数量超过阈值时显示“阈值+”，避免徽章随位数无限变宽 |
| `SCN-BADGE-04` | 自定义显示内容 | `New`、`Hot` | 可显示短文本，但应保持单行并限制长度 |
| `SCN-BADGE-05` | 小红点 | 附着在按钮、文本、邮件图标 | 只提示“存在新状态”，不表达具体数量 |

## 使用规则

- 徽章应附着在图标、导航项或对象标题附近，不能替代正文状态说明。
- 计数为零时默认隐藏，除非业务明确要求展示“0”。
- 徽章颜色只表达业务状态；不要把它作为唯一的高优先级告警手段。
- 徽章附着时以宿主右上角为锚点，避免改变宿主组件原有布局尺寸。
