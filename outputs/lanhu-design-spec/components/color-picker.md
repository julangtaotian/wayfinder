## 尺寸与样式

| 项目 | 规范 |
| --- | --- |
| 触发器 | `40px / 32px / 24px` 三档方形 |
| 默认面板 | 画板实测约 `317px` 宽 |
| 饱和度/明度区 | 画板实测约 `280px × 180px` |
| 色相轨道 | 画板实测约 `12px` 宽 |
| 边框 / 圆角 | `1px solid @component-border / 2px` |
| 操作区 | 色值输入、Clear、OK |
| 面板内边距 | 画板实测约 `9px` |
| 面板与触发器间距 | 画板实测约 `4px` |

启用透明度后，在色相选择区下方增加透明度轨道；预定义颜色以规则色块网格排列。触发器同时显示当前颜色和下拉箭头；空值显示清除标记。

### 预定义色板与场景间距

| 项目 | 画板规格 | 来源 |
| --- | --- | --- |
| 基础场景触发器间距 | 无值与有值两个触发器相隔 `104px` | 画板实测 |
| 三档尺寸间距 | Large、Default、Small 触发器之间 `24px` | 画板实测 |
| 预定义色板区域 | `272px` 宽；10 列；色块 `20px × 20px`；横纵间距 `8px` | 画板实测 |
| 第一行实色 | `#F53F3F`、`#FF7D00`、`#FADC19`、`#9FDB1D`、`#00B42A`、`#14C9C9`、`#3491FA`、`#722ED1`、`#F5319D`、`#FF6014` | 蓝湖画板色块 |
| 第二行透明色 | `rgba(0, 180, 42, 0.5)`、`rgba(20, 201, 201, 0.5)`、`rgba(52, 145, 250, 0.5)`、`rgba(245, 49, 157, 0.5)` | 蓝湖画板色块 |
| 操作文案 | 输入占位 `请输入`；清除 `Clear`；确认 `OK`；操作文字 `14px`，Clear 使用品牌色 | 画板实测 |

预定义颜色场景固定为“第一行 10 个实色 + 第二行 4 个 50% 透明色”，第二行剩余列保持为空，不能补齐为组件库默认色板。

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 触发器 | 当前色块/空值标记 + 展开箭头 | 与同尺寸输入类控件对齐 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 颜色面板 | 颜色选择区 → 色相轨道 → 可选透明度轨道 → 预定义色块/操作区 | 浮层具有边框、圆角、阴影和独立层级 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 必要交互 UI 状态

| 状态 | 触发条件 | 可见变化 | 恢复方式 | 来源 |
| --- | --- | --- | --- | --- |
| Closed / Open | 点击触发器 | 关闭时只显示触发器；打开时面板锚定触发器下方 | 选择或按关闭规则收起 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Selected | 选择颜色 | 触发器色块和输入值同步更新 | 清空后恢复空值标记 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Disabled | 禁用 | 触发器、色块边框和箭头同步降低强调，面板不可打开 | 解除禁用恢复当前值 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-COLOR-PICKER-01` | 基础用法 | 无值触发器、有值触发器、色域面板、色相轨道 | 在色域选择饱和度和明度，在竖向色相轨道切换基础色；底部可输入色值、Clear 或 OK |

| `SCN-COLOR-PICKER-03` | 预定义颜色 | 两行预设色块 + 完整自定义面板 | 高频业务色直接点击选择，同时保留自由选色能力 |
| `SCN-COLOR-PICKER-04` | 不同尺寸 | Large、Default、Small 三种触发器 | 触发器分别为 `40px / 32px / 24px`，弹出面板结构保持一致 |

## 使用规则

- 预设色板用于常用业务色；自定义颜色应有明确的输入或选择反馈。
- 当前选中颜色需要同时通过色块与文本值表达，避免仅凭视觉判断。
- 弹层关闭前应明确颜色是否已提交，避免误操作。
