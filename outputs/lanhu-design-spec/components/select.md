| 项目 | 规范 |
| --- | --- |
| 输入框 | `240px × 32px` |
| 下拉面板宽度 | `240px`，与输入框等宽 |
| 选项高度 | `32px` |
| 字号 / 行高 | `14px / 22px` |
| 水平内边距 | `12px` |
| 边框 / 圆角 | `1px solid @component-border / 2px` |
| 展开图标 | 右侧 `14px～16px` |

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 触发器 | 可选前缀 → 占位/单值/标签区 → 清空/展开图标 | 高度、内边距和状态边框按尺寸表 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 下拉面板 | 可选搜索区 → 选项列表 → 可选空态/加载/失败区 | 锚定触发器，具有边框、圆角、阴影和独立层级 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 选项 | 可选图标 → 主标签/辅助信息 → 选中勾选 | Hover、Selected、Disabled 不能只靠同一种颜色 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 研发补充

以下规则只补齐静态画板无法表达、但会影响用户所见 UI 的必要状态，不属于蓝湖视觉标注，也不规定组件库内部算法。

### 自定义模板

- 选项可显示主标签，并可按画板位置增加辅助信息或图标；辅助内容不得覆盖选中勾选区。
- 当前项沿用品牌色文字和勾选图标；禁用项仍可阅读，并使用 Disabled 视觉。
- 高亮、选中和禁用必须分别可辨；具体键盘事件和组件属性由目标项目所用组件库或实现方式决定。

### 本地筛选

- 展开后允许在触发器内输入；输入为空时恢复完整列表。
- 无匹配项时显示“无匹配数据”，清空关键字后恢复列表；筛选过程不得清除已有选择。
- 筛选后的高亮项必须位于可见结果内，当前已选值继续显示在触发器中。

### 远程搜索

- 用户输入远程关键字后，面板内容区显示“加载中”；有结果时显示选项列表，空结果显示“无匹配数据”。
- 加载失败时显示“加载失败，请重试”，重试入口位于同一反馈区域；恢复成功后替换为选项列表。
- 搜索、加载和失败期间不得清除已选值；清空输入后恢复占位或完整结果的可见状态。
- 请求频率、取消策略、竞态处理和组件卸载由具体项目的数据层与组件库负责，不属于本视觉规范。

## 使用规则

- 选项数量较多时提供搜索或分组。
- 多选的已选项应可清晰删除，不能遮挡输入区域。
- 异步加载时使用加载态，避免展示误导性的空状态。
