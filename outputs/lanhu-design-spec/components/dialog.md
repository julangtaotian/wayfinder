## 结构

对话框由标题区、关闭按钮、内容区和底部操作区组成。画板提供两种标题对齐方式：

- 默认左对齐：标题、正文和底部按钮按内容布局，按钮位于右下角。
- 居中对齐：标题与操作按钮居中；简单正文仍按内容区左对齐，表单和表格保持自身列对齐。

## 尺寸与样式

| 档位 | 宽度 | 用途 |
| --- | --- | --- |
| Small | `480px` | 系统最小对话框，不允许再小 |
| Medium | `720px` | 通用中等内容 |
| Large | `960px` | 大表单或双列内容 |
| MAX | `1232px` | 1280px 窗口减去左右各 `24px` |
| Dynamic | 窗口宽度 `80%` | 大型表格；1920px 窗口示例为 `1536px` |

| 样式项 | 规范 |
| --- | --- |
| 默认背景 | 白色容器背景 |
| 阴影 | 画板使用中等扩散投影，与页面分层 |
| 标题 | 画板实测约 `18px`，主文字色 |
| 关闭图标 | 右上角，`14px～16px` |
| 底部按钮 | `32px` 高，确认在右、取消在左 |
| 表单控件 | 默认 `32px` 高 |

对话框高度由内容决定；内容过长时固定标题与操作区，仅滚动内容区。

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 遮罩层 | 页面覆盖层 | 位于弹层下方，透明度与层级独立 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 弹层容器 | 标题区 → 内容区 → 底部操作区 | 宽度、圆角、阴影、内边距按尺寸与样式表 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 标题区 | 标题文字 + 右上角关闭按钮 | 支持左对齐或居中标题；关闭位置不变 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 必要交互 UI 状态

| 状态 | 触发条件 | 可见变化 | 恢复方式 | 来源 |

| Closed / Open | 点击触发入口 / 点击关闭、取消或完成 | Open 展示遮罩、弹层和初始内容 | 关闭后恢复触发页面视觉 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 使用规则

- 对话框用于需要用户中断当前流程并作出明确决定的场景。
- 危险操作应使用危险语义按钮，并在正文说明影响范围。
- 关闭、取消与遮罩点击的语义必须一致；提交中的对话框不应被意外关闭。
