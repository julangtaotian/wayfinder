## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-INPUT-NUMBER-01` | 基础用法 | 减号、`1.00` 输入区、加号 | 支持键盘直接输入，也支持左右按钮步进 |
| `SCN-INPUT-NUMBER-02` | 禁用状态 | 整体灰色的不可操作计数器 | 数值仍可读，输入区和两侧按钮都不可交互 |
| `SCN-INPUT-NUMBER-03` | 步数 | 自定义步长的加减示例 | 每次加减按业务步长变化；同时处理精度和上下限 |
| `SCN-INPUT-NUMBER-04` | 尺寸 | Large、Default、Small | 分别为 `180×40`、`150×32`、`120×24` |

画板示例精度为两位小数 `1.00`，业务实现按字段精度配置。

## 使用规则

- 用户需要精确输入数值时保留输入能力，不能仅提供加减按钮。
- 到达上下限时禁用对应方向的步进控制。
- 对金额、比例等场景，单位和精度规则需要与字段并列说明。
