## 状态规则

| 状态 | 表现 |
| --- | --- |
| 未选中 | 白底、中性边框、主文字 |
| 已选中 | 品牌色填充、白色勾选标记 |
| 半选 | 品牌色填充、白色短横线 |
| 禁用未选 | 禁用背景、禁用边框和文字 |
| 禁用已选 | 禁用品牌色填充，保留勾选结果 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-CHECKBOX-01` | 基础用法 | 未选、已选、半选 | 覆盖 Default、Hover、Selected、Indeterminate；Hover 只把未选框边框切换为品牌色 |
| `SCN-CHECKBOX-02` | 禁用状态 | 禁用未选、禁用已选、禁用半选 | 三种状态均保留结果信息，但不接受交互 |
| `SCN-CHECKBOX-03` | 多选框组 | 横向排列的 2～5 项 | 多项可以同时选中；超过 5 项时优先改用分组或可搜索多选 |
| `SCN-CHECKBOX-04` | 带有边框 | 大、默认、小三档；选中/未选及禁用 | 选中时方框、文字和外边框使用品牌色，禁用时整体降级 |

## 实现要点

- 点击热区应包含文字标签，不要求用户只点击小方框。
- 全选项与子项必须同步半选、全选和未选状态。
- 画板建议同组保持 `2～5` 个选项；更多选项使用可搜索多选组件。
