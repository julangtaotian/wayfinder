## 尺寸与样式

| 项目 | 规范 |
| --- | --- |
| 默认高度 | `32px` |
| 字号 / 行高 | `14px / 22px` |
| 水平内边距 | `16px` |
| 图标与文字间距 | `8px` |
| 默认圆角 | `2px` |
| 圆角按钮 | `16px`，即高度的一半 |
| 纯图标圆按钮 | `32px × 32px` |
| 描边 | `1px solid` 对应语义色或 `@component-border` |

文字按钮与普通按钮等高，但左右不加内边距。仅图标按钮使用 `button-icon` 图标，图标尺寸按通用 `14px～16px`。

## 类型与状态

| 类型 | 默认样式 | Hover | Active | Disabled |
| --- | --- | --- | --- | --- |
| Primary | 品牌常规色填充、白字 | 品牌 Hover | 品牌 Active | 品牌禁用色 |
| Default | 白底、中性边框、主文字 | 中性 Hover 背景 | 中性 Active 背景 | 禁用背景与文字 |
| Success | Success 常规色 | Success Hover | Success Active | Success Disabled |
| Info | 信息语义色 | 对应 Hover | 对应 Active | 对应 Disabled |
| Warning | Warning 常规色 | Warning Hover | Warning Active | Warning Disabled |
| Danger | Danger 常规色 | Danger Hover | Danger Active | Danger Disabled |

画板同时覆盖填充、朴素描边、圆角、禁用、文字、仅图标和图标加文字形态。

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 按钮容器 | 背景/边框层，包含内容区 | 高度、圆角、边框和状态色按尺寸/类型表 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 内容区 | 可选左图标 → 文字 → 可选右图标 | 整体水平垂直居中；图标与文字间距 `8px` | 蓝湖标注/画板实测；未标注项按研发补充 |

## 必要交互 UI 状态

| 状态 | 触发条件 | 可见变化 | 恢复方式 | 来源 |
| --- | --- | --- | --- | --- |
| Default | 未交互 | 使用对应按钮类型的默认背景、边框和文字色 | 不适用 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Hover / Active | 指针悬停 / 按下 | 按类型切换 Hover / Active 色；尺寸和内容位置不变 | 移出 / 松开恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Disabled | 禁用 | 背景、边框、文字和图标同步降级；不显示按下反馈 | 解除禁用恢复 Default | 蓝湖标注/画板实测；未标注项按研发补充 |

## 图标资产

| 图标语义 | 本地资产 | 显示尺寸 | 颜色 | 适用状态 | 替换边界 | 来源 |
| --- | --- | --- | --- | --- | --- | --- |
| 操作图标 | 蓝湖未提供独立资产 | `14px～16px` 可见图形；纯图标按钮容器 `32px × 32px` | 继承按钮文字色 | Default / Hover / Active / Disabled | 可用项目图标库等效替换；语义、画布、线宽、颜色和对齐必须一致 | 蓝湖标注 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-BUTTON-01` | 基础填充按钮 | 默认、主要、正确、信息、警告、危险 | 覆盖 Default、Hover、Active；状态只改变对应语义色，尺寸和内容位置保持不变 |
| `SCN-BUTTON-02` | 朴素按钮 | “朴素”及五种语义描边按钮 | 白色背景配语义边框和文字，用于次级操作 |
| `SCN-BUTTON-03` | 圆角按钮 | 默认及五种语义胶囊按钮 | 仍保持 `32px` 高，仅把圆角提升为高度的一半 |
| `SCN-BUTTON-04` | 圆形图标按钮 | 搜索、编辑、确认、消息、收藏、删除 | 仅显示图标，用于空间紧凑且图标语义明确的操作 |
| `SCN-BUTTON-05` | 禁用填充按钮 | 默认及五种语义按钮 | 保留按钮类型，但统一降低背景和文字强调且不可点击 |
| `SCN-BUTTON-06` | 禁用朴素按钮 | “按钮”及五种语义描边按钮 | 边框、文字和浅色背景同时进入禁用状态 |
| `SCN-BUTTON-07` | 文字按钮 | 品牌色文字按钮、禁用文字按钮 | 与普通按钮等高但无左右 Padding，适合最低强调操作 |
| `SCN-BUTTON-08` | 仅图标矩形按钮 | 编辑、分享、删除 | 使用 `button-icon`，图标居中，不附带文字 |
| `SCN-BUTTON-09` | 图标加文字按钮 | 左图标“搜索”、右图标“上传” | 图标与文字间距 `8px`，左右图标都要保持内容整体居中 |

## 实现要点

- 一个操作区只保留一个主按钮；其他操作使用次级、文字或图标按钮降级。
- 文字按钮不应通过去除背景来模拟禁用态，仍需使用对应的禁用前景色。
- 仅图标按钮必须提供可访问名称和悬浮提示。
