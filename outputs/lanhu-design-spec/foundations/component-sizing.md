# 组件尺寸与样式基线

来源：`高频组件集合-32px`、`Input 输入框`、三种中文 Form 画板及各组件高清画板。

## 规范元数据

| 字段 | 值 |
| --- | --- |
| 文档类型 | 基础规范 |
| 蓝湖画板 | `高频组件集合-32px`、`Input 输入框`、三种中文 Form 画板及各组件高清画板。 |
| 画板数量 | `5` |
| 画板场景 | 不适用：基础规范不计入组件场景总数 |
| 还原状态 | 蓝湖可见内容已记录；已通过双组件库隔离还原和全量三方视觉确认 |
| 来源判定 | 规范表中未特别注明的可见数值为“蓝湖标注”；带“画板实测”字样的值为“画板实测”；实现、使用、提交、布局和异步规则为“研发补充” |
| 测量基准 | 蓝湖 Web `@1x`；“画板实测约”项目按 `±2px` 容差验证 |

## 控件尺寸

高清画板为 1× 像素。尺寸示例中三种控件高度分别为：

| 尺寸 | 高度 | 典型场景 |
| --- | --- | --- |
| Small | `24px` | 紧凑筛选、表格内操作 |
| Default | `32px` | 后台默认控件、高频组件 |
| Large | `40px` | 大表单、强调操作、低密度页面 |

## 通用样式

| 项目 | 规范 |
| --- | --- |
| 控件字体 | `14px` |
| 控件行高 | `22px` |
| 默认边框 | `1px solid @component-border` |
| 默认圆角 | `2px` |
| 默认水平内边距 | `12px` |
| 按钮水平内边距 | `16px` |
| 图标与文字间距 | `8px` |
| 常规图标 | `14px`～`16px` |
| 默认控件高度 | `32px` |

## 常用组件固定尺寸

| 组件 | 尺寸 |
| --- | --- |
| Radio 圆形 | `14px × 14px` |
| Checkbox 方框 | `14px × 14px` |
| Switch 轨道 | `40px × 20px` |
| Switch 滑块 | `16px × 16px` |
| Badge 数字徽章 | 最小 `20px × 20px` |
| Badge 小红点 | `6px × 6px` |
| 图标圆按钮 | `32px × 32px` |
| 下拉选项 | 默认高度 `32px` |

## 宽度

- 组件示例的 Input、Select、DatePicker 常用宽度为 `240px`。
- 典型纵向表单主控件宽度约为 `392px`。
- 行内表单根据可用空间分配宽度，不把示例宽度作为业务页面的固定值。

## 状态样式

| 状态 | 处理 |
| --- | --- |
| Default | `@component-border` 边框，容器背景 |
| Hover | 对应语义 Hover 色或 `@bg-color-component-hover` |
| Focus / Active | 品牌色边框，使用对应 Active 色 |
| Disabled | `@bg-color-component-disabled` 背景、`@text-color-disabled` 文字 |
| Error | Danger 常规色边框和错误文案 |

## 阴影与层级

| 层级 | 可见处理 | 数值边界 | 来源 |
| --- | --- | --- | --- |
| 页面内联控件 | 不使用悬浮阴影，以边框、背景和状态色区分 | 阴影：`none` | 蓝湖画板实测 |
| 下拉、级联、日期、颜色等浮层 | 面板与页面背景分离，保留中性柔和投影；边框与 `2px` 圆角继续生效 | 蓝湖未提供可复制的阴影参数，不得把推测的 `box-shadow` 数值写成设计事实 | 画板实测 |
| 对话框 | 遮罩之上显示白色容器，容器具有可辨识投影 | 遮罩透明度和阴影参数在蓝湖画板中未形成可复制标注，按目标项目等效还原 | 画板实测 |
| 相对层级 | 页面内容 < 普通浮层 < 模态遮罩与对话框 | 不规定固定 `z-index`；数值由目标项目层级系统统一分配 | 研发补充 |

浮层阴影属于必须保留的视觉关系，但当前资料不足以给出可靠数值。AI 或研发实现时可以使用目标项目已有的中性浮层阴影；不得省略层级分离，也不得把组件库默认阴影误写为蓝湖标注。

## 说明

上述数值来自画板中的 24/32/40 尺寸示例及 1× 像素测量。业务自适应宽度可以变化，但高度、边框、圆角、字号和状态色应保持一致。
