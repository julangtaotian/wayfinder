# 蓝湖组件规范双组件库验收报告

验证日期：2026-07-28  
适用范围：PC 端、技术栈无关的本套 UI 规范；本轮验收实现固定为 Vue 3 + Element Plus、Vue 2 + Element UI。

## 最终结论

**两套组件库还原工程已经覆盖扩展后的全部已知场景，183 条场景均完成实现、必要状态留证和蓝湖 / Element Plus / Element UI 三方视觉确认。在本轮 30 份规范、26 个组件视图和 183 条已知场景范围内达到“可完全还原”门禁，本套 Markdown 与本地图标资产可以用于指导 AI 还原当前已知的 PC 端 UI 规范。**

Vue 3 + Element Plus 与 Vue 2 + Element UI 均已真实注册对应组件库，分别生成 26 个组件视图和 183 条场景，使用 6 个本地图标，覆盖组件库默认品牌色、尺寸、圆角、边框、文字和适用状态。两套工程均独立构建成功，Chrome 中可导航、刷新和交互。

当前 183 张蓝湖 Web `@1x` 参考裁图、366 张双库实际裁图、194 张状态裁图和 183 组三方对照均已生成；自动证据门禁为 `183 / 183` 通过、明确自动失败为 0，人工三方视觉批准为 `183 / 183`。其中 Table `24 / 24`、高频 32px 集合 `18 / 18`、Pagination `10 / 10`、Progress `5 / 5`、Transfer `8 / 8`、Upload `5 / 5`、Form `20 / 20`、DateTimePicker `14 / 14`、TimePicker `3 / 3` 通过。

## 原生历史基线

原 `validation-ui/` 是此前隔离环境未安装组件库时生成的原生 HTML/CSS/JavaScript 页面，只保留为历史基线。原生实现不得作为本轮 A-04、A-05 的通过证据，也不得抵消任一组件库实现的失败项。

旧 `0 / 29` 整页对比同样只保留追溯：它把验证页页头、侧栏、导航和卡片外壳计入差异；这些内容统称为“验证页外壳”，与当前只检查组件本体和必要状态区域的 D-09 口径不同。
