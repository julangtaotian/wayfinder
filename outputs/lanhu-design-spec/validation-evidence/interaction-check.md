## A-04 判定

结论：**失败**。

基础交互和远程搜索协议证明 Markdown 能指导模型生成一部分真实行为，但表单校验、键盘导航、单选互斥、计数器类型、级联/日期回填等关键错误说明当前文档与生成约束还不足以稳定还原研发级组件。

## 建议回写

1. 每个场景除名称外增加“组件类型”机器字段，避免 `SCN-INPUT` 与 `SCN-INPUT-NUMBER` 的前缀歧义。
2. 为表单场景明确必填字段的 HTML/组件属性、触发时机和错误节点位置。
3. 明确键盘事件只能由一个层级处理，或要求子处理器停止冒泡。
4. 为 Radio 补充组名、互斥和初始值协议。
5. 为 ColorPicker、Cascader、Date/Time Picker 和 Transfer Footer 补充“触发—状态—回填—清空—关闭”的完整状态转换。
