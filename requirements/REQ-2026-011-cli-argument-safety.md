# REQ-2026-011：CLI 参数安全加固

## 基本信息

- 状态：已验收
- 提出人：用户
- 负责人：Codex
- 目标版本：0.11.0 开发迭代
- 关联页面或模块：项目识别、初始化、检查、升级和 Wayfinder 迁移 CLI
- 关联变更：`harden-cli-argument-safety`

## 背景与目标

插件部分 CLI 入口会静默忽略未知参数，且 `--target` 缺少值时可能回退到当前工作目录。目标是在不改变合法调用、默认预览和机器输出字段的前提下，让所有受影响入口在参数无效时立即、明确且只读地失败，避免误检查或误写当前目录。

## 范围

### 包含

- 对五个已确认入口统一校验未知参数。
- 校验 `--target` 的缺失值、空值和选项令牌值。
- 确保写入型命令在参数解析失败时不创建、不更新、不迁移任何文件。
- 增加合法调用与非法参数的专用回归测试。

### 不包含

- 修改业务项目识别规则、框架矩阵或包管理器支持范围。
- 修改受管区块内容、迁移格式或 OpenSpec 运行时。
- 增加归档恢复、健康检查问题码、真实依赖安装或 CI 摘要。
- 重构现有大型测试文件。

## 当前行为

- `inspect-project.mjs --bogus` 会忽略未知参数并继续检查当前目录。
- `inspect-project.mjs --target` 会把缺失值解析为 `undefined`，随后使用当前工作目录。
- 初始化、升级和迁移入口也没有统一拒绝未知参数或无效 `--target` 值。
- `check-change.mjs` 和 `finalize-change.mjs` 已具有严格参数校验，可作为一致性基线。

## 期望行为

### 场景：合法参数保持兼容

- 前置条件：目标目录是安全、有效的前端 fixture。
- 当：使用各入口现有合法参数执行预览或只读检查。
- 则：命令保持当前退出状态和 JSON 结构。
- 并且：未显式传入 `--write` 时不修改目标文件。

### 场景：未知参数立即失败

- 前置条件：命令尚未读取或修改目标项目。
- 当：传入入口不支持的 `--bogus` 参数。
- 则：命令返回非零状态并输出“不支持的参数”中文错误。
- 并且：目标目录中不产生受管工作流文件。

### 场景：目标参数缺少有效值

- 前置条件：命令位于可写但未初始化的 fixture 中。
- 当：传入缺少值的 `--target`、空字符串值，或传入 `--target --write`。
- 则：命令返回非零状态并指出 `--target` 缺少值。
- 并且：即使命令行同时包含写入选项，也不得回退当前目录或产生文件修改。

## 页面与交互

- 入口与操作路径：Node.js CLI 参数解析。
- 字段、文案与默认值：参数名保持英文；错误信息使用中文。
- 加载态、空态、错误态、禁用态：无加载态；缺值视为空态；未知或错位选项视为错误态。
- 权限与角色差异：不涉及业务权限；写入仍需显式 `--write`。
- 设计稿链接：不适用。

## 接口与数据

- 接口文档链接：不涉及网络接口。
- 请求方法与路径：命令行 `argv`；仅识别入口声明的稳定英文选项。
- 请求字段及空值语义：值型选项后必须存在非空且不是 `--` 开头的值。
- 响应字段及状态码：合法调用保持现有 JSON；非法参数退出非零并写入中文错误。
- 鉴权、加解密或敏感信息要求：不读取凭据；参数失败发生在项目扫描与写入之前。

## 兼容性与风险

- 受影响页面、公共组件、路由、权限或接口：不影响业务页面；只影响五个插件 CLI 入口的非法参数处理。
- 历史数据与兼容策略：合法参数和机器输出保持兼容；依赖未知参数被静默忽略的调用将改为明确失败。
- 上线与回滚注意事项：实现必须保持默认 dry-run；出现兼容回归时可回退本变更，不涉及业务数据迁移。
