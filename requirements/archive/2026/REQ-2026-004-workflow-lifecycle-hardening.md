# REQ-2026-004：工作流生命周期安全与闭环强化

## 基本信息

- 状态：已验收
- 提出人：用户
- 负责人：AI 协作实施
- 目标版本：0.9.0
- 关联页面或模块：项目扫描、需求校验、变更检查、规格同步与归档
- 关联变更：`harden-workflow-lifecycle`

## 背景与目标

现有插件已经覆盖项目分析、需求整理、规划、实施、检查和归档，但部分关键门槛仍主要依赖技能文字约束：深度扫描可能纳入本地敏感配置，项目地图无法识别源码快照是否过期，需求修订没有稳定的状态迁移与证据失效顺序，检查器只能判断工作流接入状态，内部归档参考还允许确认后绕过未完成任务或规格同步。

本需求在保持现有项目兼容、默认只读和不覆盖业务内容的前提下，将上述约束收敛为可测试、可报告、不可静默绕过的确定性能力。

## 范围

### 包含

- 深度项目范围清单的敏感文件排除、Git 忽略规则、稳定指纹和优先级截断。
- Wayfinder 扫描快照字段及健康检查过期提示。
- 需求修订、实施、待验证和已验收的状态门槛。
- 关联变更范围、逐任务引用、验证证据和完成门槛校验。
- 工作流、变更和交付三层只读检查。
- 严格 OpenSpec 校验、规格同步和归档的不可绕过顺序。
- README、技能、模板、参考规则和端到端测试同步。

### 不包含

- 新增业务框架适配、Monorepo 工作区编排或新的外部依赖。
- 自动执行目标业务项目的测试、构建或发布。
- 自动迁移或改写历史需求中的业务事实。
- 自动清理当前仓库中已完成但未归档的历史变更。

## 当前行为

- 范围清单按扩展名纳入 `.env`，不读取 `.gitignore`，Wayfinder 只保存范围规则版本和数量。
- `Revise` 阶段写明只更新规划资料，与需求台账作为唯一事实源的规则存在冲突。
- 完成校验要求需求在校验前已经是“已验收”。
- 需求校验只要求 `tasks.md` 整体至少存在一个 D-* 和 A-*，没有逐任务核验或关联变更范围。
- 工作流检查只验证文件、脚本声明和内置规划引擎健康。
- 内部归档参考允许用户确认后继续归档未完成任务或跳过规格同步。

## 期望行为

### 场景：安全生成和检查项目地图

- 前置条件：目标仓库包含源码、忽略文件、本地环境配置和既有 Wayfinder。
- 当：执行深度范围收集或工作流健康检查。
- 则：真实敏感配置不会进入读取范围，范围清单生成稳定快照指纹。
- 并且：当前快照与已记录指纹不一致时只报告项目地图可能过期，不自动覆盖项目地图。
- 异常或边界：没有 Git 仓库或没有提交基线时如实记录不可用状态，不把它当作扫描失败。

### 场景：修订并实施既有需求

- 前置条件：需求已经关联活跃变更，且部分任务或验证记录可能已完成。
- 当：用户修改范围、可见行为、接口、权限或兼容决策。
- 则：先更新需求决策与验收边界，受影响 V-* 回到计划状态，受影响任务重新打开，再同步规划。
- 并且：需求仍有待确认决策或状态不允许实施时，校验阻止继续修改业务代码。
- 异常或边界：仅技术实现选择且不改变业务行为时，可以只修订设计和任务，但要保留依据。

### 场景：检查并完成变更

- 前置条件：变更进入待验证状态。
- 当：执行变更检查、交付检查或完成归档。
- 则：报告需求—规划—任务—证据一致性、实际与静态命令状态、规格同步状态和归档门槛。
- 并且：全部门槛、严格 OpenSpec 校验及规格同步成功后，需求才更新为已验收并归档。
- 异常或边界：任何门槛失败均保留活跃变更和待验证状态，不允许确认绕过为“已完成”。

## 页面与交互

- 入口与操作路径：通过 `$frontend-workflow-bootstrap`、`$frontend-change` 和 `$frontend-workflow-check` 调用。
- 字段、文案与默认值：新增机器字段使用稳定英文，用户错误和警告使用中文。
- 加载态、空态、错误态、禁用态：无图形界面；空变更、无 Git 基线、快照过期和交付阻断均返回明确结构化状态。
- 权限与角色差异：不涉及业务角色；文件读写仍遵循 Codex 与仓库权限。
- 设计稿链接：不适用。

## 接口与数据

- 接口文档链接：不适用。
- 请求方法与路径：不涉及网络接口；继续使用插件内置 Node.js 脚本和 OpenSpec 运行时。
- 请求字段及空值语义：新增 JSON 字段需稳定区分 `null`、`false`、空数组和缺失值。
- 响应字段及状态码：只读检查成功使用退出码 0；阻断性错误使用非零退出码；警告不伪装为错误。
- 鉴权、加解密或敏感信息要求：不读取和不输出真实环境变量值、凭据或密钥内容。

- 受影响页面、公共组件、路由、权限或接口：不涉及业务页面；影响所有使用本插件的项目扫描、需求和变更流程。
