# REQ-2026-033：核心脚本可维护边界

## 基本信息

- 状态：已验收
- 提出人：用户
- 负责人：Codex
- 目标版本：0.18.x
- 关联页面或模块：完成归档、需求决策校验、验证证据、仓库体积门禁与五平台 CI
- 关联变更：`modularize-core-workflow-scripts`

## 背景与目标

仓库持续体积治理已经生效，但三个共享入口再次接近脚本单文件 800 行预算：`finalize-change.mjs` 为 785 行、`validate-requirement-decisions.mjs` 为 743 行、`verification-evidence.mjs` 为 712 行。继续在入口文件累加逻辑会增加 AI 定位与读取成本，并使下一次正常维护容易被体积门禁阻断。

本阶段按用户确认的优化顺序，先把三个入口拆成职责稳定的内部模块，保持公开导出、CLI 参数、机器字段、错误码、完成恢复语义和验证证据边界不变。本阶段不同时修改 CI 缓存、运行时存储或仓库识别，以便聚焦证明纯重构没有改变行为。

## 范围

### 包含

- 拆分 `finalize-change.mjs` 的恢复、归档后审计或协作职责，保留 `finalizeChange` 等公开入口。
- 拆分 `validate-requirement-decisions.mjs` 的 Markdown 解析、变更范围或交付阶段校验职责，保留 `validateRequirementDecisions` 与 CLI。
- 拆分 `verification-evidence.mjs` 的清单、证据文件或记录校验职责，保留现有公开导出与 CLI。
- 扩展现有手写回归，覆盖公开导出、正常路径、失败路径、重复恢复、Windows/POSIX 路径样本和稳定机器字段。
- 保持三个原入口不超过 600 行，所有新增脚本不超过 800 行。

### 不包含

- 修改 `.github/workflows/validate.yml`、Git LFS 缓存或五平台矩阵。
- 把平台运行时迁出 Git LFS、压缩二进制或删除本地缓存。
- 修改 `check-project.mjs` 的插件仓库识别。
- 修改任何用户可见业务行为、OpenSpec 规范语义、需求格式或证据 schema。
- 放宽仓库体积预算或建立定时清理任务。

## 当前行为

- 三个入口分别为 785、743、712 行，靠近 800 行阻断预算。
- 入口同时承担 CLI、解析、编排、文件校验与交付阶段判断，AI 为局部修改时需要读取较大范围。
- 现有公开导出被多个手写测试和其他脚本直接导入，拆分必须保持导入兼容。

## 期望行为

### 场景：维护完成归档流程

- 前置条件：调用方继续从 `finalize-change.mjs` 导入公开函数或执行现有 CLI。
- 当：执行预览、正式归档、部分失败恢复或重复恢复。
- 则：输出、归档目标、需求重写、证据引用迁移和错误码与拆分前一致。
- 并且：入口只负责稳定 API 与总编排，恢复/审计协作位于内部模块。

### 场景：校验需求决策

- 前置条件：需求处于 plan、implement、precomplete 或 complete 任一阶段。
- 当：通过现有函数或 CLI 校验决策、验收、证据、测试策略和变更任务引用。
- 则：相同输入产生兼容的 `ok`、errors、warnings、status 和退出状态。
- 并且：Markdown 解析与交付阶段判断具有清晰模块边界。

### 场景：生成或审计验证证据

- 前置条件：调用方执行自动证据命令或读取 schema v2 清单。
- 当：命令成功、子进程失败、证据文件越界、摘要不匹配或外部证据被记录。
- 则：日志、描述符、清单校验、可信边界和稳定机器字段保持兼容。
- 并且：Windows 与 POSIX 路径样本继续使用一致规范化规则。

## 页面与交互

- 入口与操作路径：Node.js 函数和 CLI；不涉及业务页面。
- 字段、文案与默认值：命令参数和 JSON 字段保持稳定英文；人类错误信息保持中文语义。
- 加载态、空态、错误态、禁用态：一次性 CLI 无加载或禁用态；空诊断返回空数组；解析、路径、子进程和归档失败继续失败关闭。
- 权限与角色差异：不新增权限和外部连接。
- 设计稿链接：不适用。

## 兼容性与风险

- 受影响入口参与完成归档、需求门禁和可信证据，虽然不改变规格，仍属于共享发布链。
- 移动函数时容易遗漏闭包依赖、默认服务注入、路径规范化或 CLI 入口判断，必须依靠现有公开导入和端到端 fixture 回归。

- 不修改 CI 本身；本阶段外部证据只核对拆分后的精确提交在现有五平台矩阵中全部成功。
