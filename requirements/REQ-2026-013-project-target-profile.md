# REQ-2026-013：轻量项目终端画像

## 基本信息

- 状态：已验收
- 提出人：用户
- 负责人：Codex
- 目标版本：0.11.0 开发迭代
- 关联页面或模块：项目识别、初始化、升级、检查、Wayfinder 与 OpenSpec 项目上下文
- 关联变更：`add-project-target-profile`

## 背景与目标

插件当前能够识别 Vue、React、Vite、Webpack 和包管理器，但不能区分项目主要面向桌面 Web 还是移动 Web，容易让需求分析、交互边界和验证计划缺少终端事实。目标是在不扩张为框架百科或独立终端工作流的前提下，增加一个轻量、可追溯、可扩展的终端画像，为后续需求分析、变更实施和验证提供稳定输入。

## 范围

### 包含

- 从 `package.json` 依赖生成轻量终端画像。
- 支持 `desktop`、`mobile`、`mixed` 和 `unknown` 四个稳定值。
- 输出可追溯、排序稳定的依赖证据和证据来源。
- 将画像加入项目识别、项目检查、AGENTS、Wayfinder 和 OpenSpec 上下文。
- 验证初始化、升级、检查和既有字段兼容。

### 不包含

- 微信原生小程序、uni-app、Taro、Remax 或其他小程序框架识别。
- 自动断言项目是响应式布局；`mixed` 只表示同时存在桌面与移动依赖证据。
- 根据 CSS、视口标签、目录名、项目名或单个页面内容猜测终端。
- 新增终端专用 CLI、配置文件、模板体系或第三方依赖。
- 安装或执行 fixture 的真实第三方包。

## 当前行为

- PC Web、移动 H5 和双端项目在相同 Vue/React 技术栈下得到相同 preset。
- 识别 JSON、项目检查、AGENTS、Wayfinder 和 OpenSpec 上下文没有终端画像字段。
- 需求分析只能依赖用户临时说明或 AI 自行推断终端边界。

## 期望行为

### 场景：识别单一桌面或移动证据

- 前置条件：`package.json` 只包含已支持的桌面型或移动型 UI 依赖。
- 当：执行项目识别、初始化或检查。
- 则：`targetProfile.formFactor` 分别返回 `desktop` 或 `mobile`。
- 并且：`source` 和 `evidence` 明确指出判断来源，不改变现有 preset 与命令。

### 场景：存在冲突或缺少证据

- 前置条件：项目同时包含桌面与移动依赖，或者没有任何已支持的终端型依赖。
- 当：执行项目识别。
- 则：分别返回 `mixed` 或 `unknown`。
- 并且：系统不得把 `mixed` 描述为已确认响应式，也不得根据目录名补造证据。

### 场景：同步并升级受管上下文

- 前置条件：项目尚未初始化，或已存在带合法受管标记的旧版工作流文件。
- 当：执行初始化或显式升级。
- 则：AGENTS、Wayfinder 和 OpenSpec 受管区块包含当前终端画像。
- 并且：升级只修改受管区块，项目自定义内容保持不变。

## 页面与交互

- 入口与操作路径：项目识别、初始化预览/写入、升级预览/写入和项目检查 CLI。
- 字段、文案与默认值：机器字段使用稳定英文；无证据默认 `unknown`；模板说明使用中文。
- 加载态、空态、错误态、禁用态：无页面加载态；缺少终端证据属于正常空态，不视为命令错误。
- 权限与角色差异：不涉及业务权限；写入仍需显式 `--write`。
- 设计稿链接：不适用。

## 接口与数据

- 接口文档链接：不涉及网络接口。
- 请求方法与路径：读取目标根目录 `package.json`，不联网、不安装依赖。
- 请求字段及空值语义：合并 dependencies、devDependencies 和 peerDependencies；没有匹配依赖时证据数组为空。
- 响应字段及状态码：合法项目继续退出 0；新增 `targetProfile.formFactor/source/evidence`，现有字段保持不变。
- 鉴权、加解密或敏感信息要求：不读取凭据；证据只记录匹配到的公开包名。

## 兼容性与风险

- 受影响页面、公共组件、路由、权限或接口：不影响业务项目页面；影响插件共享项目识别结果和受管上下文模板。
- 历史数据与兼容策略：新增字段保持向后兼容；旧项目只有显式升级才更新受管区块，未受管文件继续保留。
- 上线与回滚注意事项：依赖证据只能提供保守画像，不能替代需求确认；发生误判时可回退画像输出，不涉及业务数据迁移。
