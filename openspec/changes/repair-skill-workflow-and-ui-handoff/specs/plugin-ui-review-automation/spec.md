## ADDED Requirements

### Requirement: 默认 UI 发现必须支持可审计的修复上下文补齐
系统 SHALL 提供预览及显式写入候选的入口，绑定已有运行、场景和发现身份，检查源码摘要、唯一锚点、限定范围和验证断言。保留原始 findings、报告和截图，不将所有问题自动改为可修复。对应 REQ-2026-043 D-03 与 A-02。

#### Scenario: 有效候选接续
- **WHEN** 高置信度发现获得完整源码上下文并通过校验
- **THEN** 预览不写文件；显式写入只更新候选，重复同一输入保持幂等；原有授权门禁继续生效

#### Scenario: 失效或不安全输入
- **WHEN** 发现身份、场景、源码摘要或锚点失效，或路径越界、经过符号链接
- **THEN** 拒绝写入并给出稳定机器诊断；不执行候选命令

#### Scenario: 原基线复验
- **WHEN** 候选补齐后问题仍存在或源码修复后消失
- **THEN** 同一问题分别归入 remaining 或 resolved，不因补齐源码改变原始发现身份
