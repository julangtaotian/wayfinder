## MODIFIED Requirements

### Requirement: 响应式布局规范必须吸收还原修正并使用可读画板名称

系统 MUST 将真实项目还原确认的通用 UI 约束写入正式响应式规范，并在响应式正文与 README 公共索引中以原始尺寸、列数和状态或用途命名 12 张参考画板，不得要求 AI 解释 `copy / copy 2` 等源文件名。

本要求实现 `D-21`，并由 `A-11` 验证。

#### Scenario: 真实还原修正进入正式规范

- **WHEN** AI 读取响应式表单布局规范
- **THEN** 文档必须明确字段控件占满等分列、主操作使用 `#FF6014`、组件库默认主题不得覆盖规范、操作组不可拆分且页面不得横向越界

#### Scenario: 画板展示名直接表达布局含义

- **WHEN** AI 或研发读取正文中的 12 张画板映射或 README 画板索引
- **THEN** 每张画板展示名必须包含原始尺寸和列数或用途，同尺寸同列数画板必须再以基础、空数据或数据状态区分，两个索引区均不得出现 `copy` 或 `copy 2`

#### Scenario: README 与正文名称保持一致

- **WHEN** AI 从 README 定位响应式表单布局规范
- **THEN** README 第 34～45 行的 12 个画板名称与正文映射中的规范化名称必须集合相同且顺序一致

#### Scenario: 可读命名不破坏追溯

- **WHEN** 画板展示名从蓝湖源命名迁移为可读名称
- **THEN** 文档路径、README 链接、画板数量和 12 个稳定画板 ID 必须保持不变

#### Scenario: 验证专用实现不得进入通用规范

- **WHEN** 双组件库验证使用 iframe、组件库类名、截图路径或其他测试设施
- **THEN** 正式响应式规范不得把这些实现细节写成通用 UI 要求
