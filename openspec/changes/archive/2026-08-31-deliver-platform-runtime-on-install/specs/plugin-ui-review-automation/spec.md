## MODIFIED Requirements

### Requirement: 平台成品必须安全暂存并满足带余量的体积预算
系统 MUST 提供默认只预览、显式 `--write` 才执行的平台准备入口，并 MUST 只向位于允许范围内的全新外部暂存目录写入。入口在安装或升级阶段 MUST 使用固定 Playwright 版本为当前原生平台准备 Chromium/FFmpeg 与许可，再生成完整本地 marketplace 成品；源码运行时不需要预先存在平台二进制。成品 SHALL 完整保留插件共享 Playwright、OpenSpec、Skills、脚本、当前平台 Chromium/FFmpeg、许可和重建后的完整性清单，同时 MUST 排除其他四个平台的元数据、清单和浏览器资产。macOS ARM64、macOS x64、Linux x64、Linux ARM64 与 Windows x64 成品大小 MUST 分别不超过 260、260、330、420、340 MiB；任一条件不满足时 MUST 阻止发布并清理未完成暂存目录。（D-03、D-04、D-05、D-08、D-09、D-13；A-01、A-02、A-03、A-05）

#### Scenario: 预览平台成品不产生写入
- **WHEN** 调用方在受支持原生平台提供安全输出路径但未传入 `--write`
- **THEN** 系统只返回平台键、固定版本、输出路径、体积预算、预计下载与排除平台，不创建目录、不下载资产、不修改规范源码或执行 Codex 安装命令

#### Scenario: 生成只包含一个平台的完整成品
- **WHEN** 调用方显式使用 `--write` 向不存在的安全暂存目录准备当前原生平台成品
- **THEN** 系统从固定官方源得到目标平台资产，复制所有共享插件内容，只保留目标平台元数据和资产，重建共享与该平台清单，并输出实际字节数、预算、余量、许可来源和真实 Chromium 冒烟结果
- **AND** 成品结构校验能够识别平台成品模式，不要求其他四个平台文件，同时确认它们没有残留，安装后的 UI Review 运行阶段不再联网下载

#### Scenario: 网络超时或下载失败
- **WHEN** 固定官方下载单次超过十分钟或连续三次没有得到完整目标资产
- **THEN** 系统以稳定 `code`、`status`、`target` 和真实子进程信息失败，清理本次暂存，不覆盖已有成品或已安装旧插件，也不自动切换未知镜像

#### Scenario: 使用既有代理环境
- **WHEN** 用户环境已经提供适用于官方下载的代理变量
- **THEN** 平台准备子进程继承这些变量，但日志、报告、机器证据和错误消息不得记录代理凭据或包含凭据的代理值

#### Scenario: 离线环境安装已验证成品
- **WHEN** 用户把同平台、同插件版本且完整性与许可校验通过的 marketplace 成品复制到离线环境
- **THEN** Codex 可以从该本地路径安装插件，插件加载和 UI Review 使用成品内置运行时，不需要重新下载或访问业务项目依赖

#### Scenario: 输出越界、已存在或成品超预算
- **WHEN** 输出路径越出允许暂存根、指向仓库或用户主目录、经过符号链接越界、已经存在，或生成后的实际体积超过当前平台预算
- **THEN** 系统以稳定机器字段和中文错误停止，不覆盖已有文件，不保留半成品，也不修改仓库规范源码资产

#### Scenario: Linux ARM64 原生去除调试符号
- **WHEN** `linux-arm64` 原生 Runner 显式生成平台成品
- **THEN** 系统只对暂存成品中的 Chromium headless shell 去除调试符号，使用同版本 Linux x64 官方包补齐许可，再重建成品清单并真实启动 Chromium 产生截图
- **AND** 缺少原生工具、调试符号仍残留、许可缺失、摘要重建失败或浏览器无法启动时阻止发布

#### Scenario: 其他平台不执行 Linux ARM64 二进制改写
- **WHEN** 当前原生平台不是 `linux-arm64` 或目标成品不是 `linux-arm64`
- **THEN** 系统不得执行 Linux ARM64 去符号步骤，也不得交叉修改其他平台规范源或暂存二进制

#### Scenario: 重复准备和升级失败
- **WHEN** 相同输出已经存在，或新版本准备、结构、完整性、体积、许可与冒烟任一失败
- **THEN** 系统不得静默覆盖旧成品；受控升级必须先在独占暂存中完成全部检查再发布，失败时旧成品保持可用且本次暂存被精确清理
