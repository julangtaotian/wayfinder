本规范落实 D-04、D-05、D-06、D-08、D-09、D-10、D-11、D-12、D-15、D-16，并由 A-02、A-03、A-04、A-05、A-06 验收。

## ADDED Requirements

### Requirement: AI 还原必须隔离蓝湖答案并包含本地资产

系统 MUST 在全新的 AI 进程和最小工作目录中执行还原，输入只能包含整理后的 Markdown、Markdown 明确引用的本地图标/字体等资产、实现目标和空输出目录。

#### Scenario: 隔离输入成功

- **WHEN** 启动 AI 还原
- **THEN** 运行记录必须列出 Markdown 与本地资产的文件及哈希，并证明未提供蓝湖链接、原始画板、截图、既有 UI 文件或本任务对话

#### Scenario: 独立 AI 无法启动

- **WHEN** 本机无法启动新的隔离 AI 进程
- **THEN** A-04 必须记为阻断，系统不得用已读取蓝湖的当前会话替代

#### Scenario: AI 遇到文档歧义

- **WHEN** AI 无法从 Markdown 确定视觉或交互值
- **THEN** AI 必须把歧义写入运行记录，不得猜测后把该项报告为通过

### Requirement: 还原样例必须覆盖全部已知组件和场景

系统 SHALL 分别生成 Vue 3 + Element Plus、Vue 2 + Element UI 两套可本地启动、可导航和可刷新的组件规范样例，并在每套样例中为全部已知组件和 183 条场景提供稳定定位。两套实现 MUST 真实注册并使用对应组件库，且 MUST 服从 Markdown 中的显式视觉值。既有 25 个组件视图、159 条场景产物只作为 Table 扩展前的历史基线，不满足扩展后验收。

#### Scenario: 生成 Element Plus 实现

- **WHEN** 隔离 AI 生成 Vue 3 验收工程
- **THEN** 工程必须声明并加载 Element Plus、记录运行时版本、用真实 `el-*` 组件覆盖 26 个组件视图和 183 条场景，并覆盖冲突的默认主题

#### Scenario: 生成 Element UI 实现

- **WHEN** 隔离 AI 生成 Vue 2 验收工程
- **THEN** 工程必须声明并加载 Element UI、记录运行时版本、用真实 `el-*` 组件覆盖 26 个组件视图和 183 条场景，并覆盖冲突的默认主题

#### Scenario: 禁止原生实现替代组件库

- **WHEN** 自动测试或运行时证据发现某套工程未注册对应组件库、使用原生表单控件替代目标组件或只复用历史 `validation-ui/`
- **THEN** 该套 A-04、A-05 必须失败，另一套通过不得抵消

#### Scenario: 生成全部场景锚点

- **WHEN** 自动测试分别读取两套还原页面
- **THEN** 每套页面中 26 份组件类规范的 183 条场景必须各有唯一、可见的真实组件库实例定位标识

#### Scenario: 刷新任一组件视图

- **WHEN** 用户直接打开或刷新任一套工程的任一规范视图
- **THEN** 页面必须独立重建且不依赖蓝湖会话、本任务内存或业务外部服务

### Requirement: 必要交互 UI 状态必须可观察

系统 SHALL 对所有适用组件提供文档定义的 Default、Hover、Focus、Active、Selected、Disabled、Loading、Empty、Error、展开/收起和值回填等必要可见状态。

#### Scenario: 用户操作组件

- **WHEN** 用户触发规范明确的鼠标、键盘或值变化
- **THEN** 尺寸、颜色、字体、边框、图标、文案和层级必须按规范进入对应可见状态

#### Scenario: 触发空态和错误态

- **WHEN** 以本地受控数据触发空态、表单错误、上传失败或加载失败
- **THEN** 页面必须展示规范定义的空态或错误态视觉，并能恢复到规范中的初始状态

#### Scenario: 组件库提供额外内部行为

- **WHEN** 所选组件库提供规范未定义的键盘、异步或生命周期行为
- **THEN** 系统可以继承该内部行为，但不得因此改变规范明确的可见状态

### Requirement: 视觉检查必须针对组件区域使用显式门禁

系统 SHALL 按蓝湖 Web `@1x` 检查组件本体和状态样例区域，并分别记录几何、颜色、字体、图标、文案、初始状态和非结构像素差异。验证页外壳 MUST 排除在视觉门禁外。

#### Scenario: 检查显式尺寸和间距

- **WHEN** 比较蓝湖参考画板与还原截图
- **THEN** 所有明确标注或测量的尺寸和间距偏差必须不超过 `±2px`

#### Scenario: 检查显式颜色

- **WHEN** 规范包含明确 HEX
- **THEN** 还原页面对应视觉属性必须与 HEX 完全一致

#### Scenario: 检查文案和场景

- **WHEN** 逐页核对可见内容
- **THEN** 文案和场景数量必须完全一致，任何缺失或额外场景均为失败

#### Scenario: 检查图标资产

- **WHEN** 组件场景包含本地图标引用
- **THEN** 还原组件必须使用该资产或满足文档替换边界的等效图标，且尺寸、颜色、线宽和对齐符合规范

#### Scenario: 排除验证页外壳

- **WHEN** 还原样例为了导航或说明增加页头、侧栏、卡片或文档排版
- **THEN** 视觉检查必须只截取对应组件和状态区域，不得把验证工具布局记为设计差异

#### Scenario: 验收示例宽度不足

- **WHEN** 两列场景卡片无法容纳组件规范中的显式宽度
- **THEN** 验收页必须退回单列展示，组件和操作区不得越出场景卡片或遮挡相邻场景

#### Scenario: 蓝湖参考画板包含透明工作区

- **WHEN** 原始画板使用透明像素表达经典页面工作区背景
- **THEN** 参考裁图与两套实现必须以 `#F0F2F5` 为承载底色叠加源画板 `rgba(0, 0, 0, 0.16)` 工作区层，使可见合成色约为 `#CACCCF`，不得只显示承载底色或把透明像素解释为纯黑

#### Scenario: 核对经典表格页结构与操作列

- **WHEN** 比较 `SCN-TABLE-22`、`SCN-TABLE-23`、`SCN-TABLE-24` 与三张蓝湖经典页面
- **THEN** 两套实现必须保留 `200px` 侧栏、`176px` 页头、分档筛选换行、9 行统一数据、仅横向分隔的表格和右下分页；操作列必须显示三个 `#FF6014` 无边框文字链接“详情 / 编辑 / 删除”，分页当前页为 `1` 且不出现跳页输入

#### Scenario: 出现字体抗锯齿差异

- **WHEN** 差异仅来自系统字体渲染或抗锯齿
- **THEN** 报告必须单独记录该非结构差异，不得用整体像素相似度覆盖几何或颜色错误

#### Scenario: 建立全部场景的三方视觉证据

- **WHEN** 执行 A-05 全量视觉验收
- **THEN** 183 条唯一场景必须各有蓝湖 `@1x` 组件区域参考裁图、Element Plus 实际裁图和 Element UI 实际裁图，并记录显式几何、HEX、文案、图标和初始状态结果

#### Scenario: 场景包含必要操作后状态

- **WHEN** 场景规范要求 Hover、Focus、Active、Selected、Disabled、Loading、Empty、Error、展开/收起或值回填
- **THEN** 证据行必须记录可复现操作、操作后可见值和两套实际状态截图；缺少任一套状态证据时该场景失败

#### Scenario: 任一场景证据不完整

- **WHEN** 任一场景缺少参考裁图、任一组件库实际裁图、显式值结果或适用状态结果
- **THEN** A-05 必须保持未通过，不得用其他场景或另一套组件库的通过结果抵消

### Requirement: 验证结论必须可审计且不夸大

系统 MUST 在验证报告中逐项映射 A-01 至 A-06、隔离输入、本地图标资产、两套真实组件库运行时、各自全部已知组件、183 场景、必要状态和组件区域视觉证据。

#### Scenario: 所有门禁通过

- **WHEN** A-01 至 A-06 全部通过，且 Element Plus、Element UI 两套子门禁均通过
- **THEN** 报告可以将本次结论写为“可用于 AI 还原本套 UI 规范”

#### Scenario: 任一门禁失败

- **WHEN** 任一套存在未映射组件/场景、未真实加载对应组件库、缺失资产、显式视觉超差、必要状态失败或输入泄漏
- **THEN** 报告必须写“尚不足以用于稳定还原”，并列出文件、画板、差异、来源等级和最小补充清单

#### Scenario: 限定结论适用范围

- **WHEN** 报告给出最终结论
- **THEN** 报告必须说明结论只适用于本次 Markdown、本地资产、指定模型/提示词和已知组件，不得扩展到所有模型、组件库或未来页面
