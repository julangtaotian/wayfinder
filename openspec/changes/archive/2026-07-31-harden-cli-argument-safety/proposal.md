## Why

五个插件 CLI 入口仍会静默忽略未知参数，并可能在 `--target` 缺少有效值时回退当前工作目录。需要在任何项目检查或写入前拒绝无效参数，补齐插件现有安全边界。（D-01、D-02）

## What Changes

- 为项目识别、初始化、检查、升级和 Wayfinder 迁移入口增加一致的未知参数校验。（D-01、D-02）
- 拒绝 `--target` 缺失、空值或以另一个 `--` 选项作为值，并保证失败时不执行项目逻辑或文件写入。（D-02）
- 保持合法参数、默认 dry-run、现有 JSON 字段、受管文件和内置 OpenSpec 行为不变。（D-03）
- 新建专用 CLI 参数安全测试，并通过完整统一门禁验证共享入口兼容性。（D-04、D-05）
- 不纳入归档恢复、结构化诊断、真实框架构建、Monorepo、AI 评分、测试拆分或 CI 报告增强。（D-06）

## Capabilities

### New Capabilities

- `cli-argument-safety`: 约束插件 CLI 对合法参数、未知参数、缺少值和选项令牌值的兼容及安全失败行为。

### Modified Capabilities

- 无。

## Impact

- 受影响代码：五个插件 CLI 脚本的参数解析，以及新的专用安全测试。
- 兼容性：依赖未知参数被静默忽略的错误调用会改为非零失败；所有合法调用保持兼容。
- 依赖与系统：不增加依赖，不修改 OpenSpec 运行时、业务项目文件格式或 CI 入口。
- 关联需求：`requirements/REQ-2026-011-cli-argument-safety.md`。
