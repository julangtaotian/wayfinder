## ADDED Requirements

### Requirement: 受管 Verify 必须提供一次通过的结果记录路径

受管 Verify MUST 保持证据预览只读、显式写入只执行一次聚焦命令，并 MUST 在成功后允许一次性更新验证结果事实，再运行一次 complete 校验。公开流程 MUST 区分绑定字段与完成事实，且在 CLI 已返回已知结构化诊断时 MUST NOT 要求读取校验器实现源码。（D-04、D-06；A-01、A-04）

#### Scenario: 正常受管验证闭环

- **WHEN** 计划命令预览有效，显式执行以零状态完成且命中计划定位
- **THEN** 工作流生成机器证据、更新 V/TC/验收完成事实，并以一次 complete 校验结束，不重复执行测试或读取校验器实现

#### Scenario: 已知语义过期诊断

- **WHEN** complete 返回带稳定 code、status、target、绑定版本和新旧绑定的已知识别结果
- **THEN** 工作流依据公开合同报告真实语义变化或重新生成受影响证据，不通过源码回读、篡改清单或无关全量测试规避门禁

#### Scenario: 未知结构故障

- **WHEN** 结构化字段缺失、互相矛盾或出现未公开的错误 code
- **THEN** 工作流可以进入最小实现级诊断，但必须保持业务源码、既有测试和已通过证据的所有权边界
