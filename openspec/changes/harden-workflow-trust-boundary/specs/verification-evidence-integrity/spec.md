## ADDED Requirements

### Requirement: 严格机器证据必须绑定当前验收语义
新生成的严格本地机器证据 MUST 使用 schema v2，并 MUST 绑定最新需求修订、当前 V-*、相关 D-* 与 A-* 的可观察断言以及对应 TC-* 定义的稳定语义摘要。执行日期、结果、证据路径、复选状态和其他完成后变化字段 MUST NOT 进入该摘要；相关语义变化后，旧证据 MUST 被判为过期。（D-04、D-05，A-03、A-06）

#### Scenario: 相关验收或测试定义变化
- **WHEN** v2 证据生成后，其关联 D-*、A-*、V-* 可观察断言、TC-* 定义或需求修订基线发生变化
- **THEN** 严格校验返回稳定的语义证据过期诊断和对应 evidenceId，不得形成 passed 结论

#### Scenario: 只更新验证结果字段
- **WHEN** v2 证据生成后只更新执行日期、结果、证据位置、验收复选状态或其他明确排除的完成字段
- **THEN** 语义摘要保持稳定，不因生命周期闭环自身产生自引用过期

#### Scenario: 无关需求说明变化
- **WHEN** 需求中与当前 V-*、关联验收和对应测试定义无关的说明发生变化
- **THEN** 系统不得无差别使该 V-* 的证据过期

#### Scenario: 活动严格变更仍提供 schema v1
- **WHEN** 显式启用严格证据合同的活动变更只提供 schema v1 清单
- **THEN** 系统返回迁移所需的稳定阻断诊断，不得把历史格式升级为新的严格通过

#### Scenario: 历史只读需求保留 schema v1
- **WHEN** 未启用严格合同的历史需求引用仍可识别的 schema v1 清单
- **THEN** 系统保持只读并报告兼容或迁移提示，不自动改写历史证据

### Requirement: 严格校验必须复算持久证据完整性
schema v2 清单 MUST 为命令日志和声明附件逐项记录安全项目相对路径、字节数和 SHA-256。严格完成校验 MUST 重新检查路径范围、符号链接边界、文件存在性、字节数和摘要，任一必需产物不一致时 MUST 使对应证据失败，且 MUST NOT 为此重跑原命令。（D-06，A-03、A-06）

#### Scenario: 日志或附件保持不变
- **WHEN** v2 清单引用的全部必需日志和附件仍位于项目安全范围且大小与摘要一致
- **THEN** 持久产物完整性检查通过，并继续执行语义、新鲜度和具体 kind 合同校验

#### Scenario: 持久产物缺失或被修改
- **WHEN** 任一必需日志或附件不存在、大小变化或 SHA-256 不一致
- **THEN** 系统返回具体目标和稳定完整性错误，不得由其他仍存在的产物掩盖失败

#### Scenario: 持久产物经符号链接越界
- **WHEN** 清单中的词法相对路径通过目标或祖先符号链接解析到项目外
- **THEN** 系统失败关闭且不读取项目外内容

### Requirement: 外部 CI 记录不得自我提升信任等级
没有由插件可信远程读取链生成并可复核的远程回执时，`external-ci` 清单 MUST 标记为 `external-recorded`，即使本地字段声明任务通过或远程已验证，也 MUST NOT 满足严格自动通过门禁。人工复核 MAY 作为明确的人工验证事实记录，但 MUST NOT 描述为插件远程核验。（D-08、D-09，A-05、A-06）

#### Scenario: 本地清单自声明远程已验证
- **WHEN** external-ci JSON 包含 URL、精确提交、passed jobs，并由本地字段把 `remotelyVerified` 声明为 true，但没有可信远程回执
- **THEN** 系统仍输出 `external-recorded` 和非通过信任状态，不接受该记录满足自动 V-* 门禁

#### Scenario: 用户人工复核真实矩阵
- **WHEN** 用户查看同一提交的真实 CI 并把结果记录为人工 V-*
- **THEN** 交付资料明确标记人工复核及运行链接，不把该事实改写成插件已远程验证
