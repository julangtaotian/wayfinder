## 尺寸与样式

| 项目 | 规范 |
| --- | --- |
| 单选圆形 | `14px × 14px` |
| 标签字号 / 行高 | `14px / 22px` |
| 控件与标签间距 | `8px` |
| 按钮组高度 | `24px / 32px / 40px` |
| 按钮组边框 | `1px solid @component-border` |
| 按钮组圆角 | 首尾 `2px`，相邻项共用边框 |

选中圆点和选中按钮使用品牌常规色；按钮组的选中项为品牌填充、白字。禁用态使用禁用背景、边框和文字。

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 选择圆点 | 圆形外框 + 选中内圆 | `14px～16px`，内外圆同心 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 标签 | 位于选择圆点右侧 | 间距 `8px`，文字垂直居中 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 单选组 | 多个 Radio 横向或纵向排列 | 同组只保留一个 Selected 视觉 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 必要交互 UI 状态

| 状态 | 触发条件 | 可见变化 | 恢复方式 | 来源 |
| --- | --- | --- | --- | --- |
| Default / Hover | 未选择 / 悬停 | Default 中性边框；Hover 品牌边框 | 移出恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Selected | 值与当前项匹配 | 品牌边框和品牌内圆，标签按画板状态 | 选择同组其他项后恢复未选 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Disabled | 禁用未选或已选 | 圆点、边框和标签同步使用禁用色，保留当前值视觉 | 解除禁用恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-RADIO-01` | 基础用法 | 未选、已选 | 已选项使用品牌色圆环和中心圆点，同组只能保留一个值 |
| `SCN-RADIO-02` | 禁用状态 | 禁用未选、禁用已选 | 禁用已选仍要保留当前结果，二者都不可响应点击 |
| `SCN-RADIO-03` | 单选框组 | 横向排列的 3 个选项 | 画板实例展示三项；业务使用建议维持 2～5 项，适合数量少且需要同时比较的互斥选项 |
| `SCN-RADIO-04` | 按钮样式 | 四项按钮组的完整状态矩阵 | 相邻项共用边框；选中项品牌色填充；必须覆盖四个选中位置、整组未选、四个局部禁用位置、禁用项与选中项组合、整组禁用，不能只实现单个默认示例 |
| `SCN-RADIO-05` | 带有边框 | 大、默认、小三档；每档各含选中/未选、禁用已选/禁用未选 | 单个 Radio 外增加容器边框，选中时边框和文字使用品牌色；禁用已选不得残留品牌色 |

## 使用规则

- 仅在选项互斥且必须从中选一时使用单选框。
- 默认值应符合多数用户场景，或明确要求用户主动选择。
- 同组单选项使用相同的标签结构和排列方向。
- 画板建议一个单选组保持 `2～5` 个选项；更多选项改用 Select。
