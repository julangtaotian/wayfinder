## 状态规则

| 状态 | 视觉样式 |
| --- | --- |
| 默认 | 容器背景、`@component-border` 边框、占位文字色 |
| Hover | 中性 Hover 背景或边框增强 |
| 聚焦 | 品牌色边框，输入光标可见 |
| 错误 | Danger 常规色边框，并显示字段级错误文案 |
| 禁用 | 禁用背景、禁用文字，不可编辑 |

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 输入框容器 | 可选前缀区 → 文本/占位区 → 可选后缀/状态区 | 三种高度和 `240px` 示例宽度按尺寸表 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 反馈区 | 字数、说明或错误信息位于输入框内部右侧或下方 | 不得覆盖输入文本和图标点击区 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 必要交互 UI 状态

| 状态 | 触发条件 | 可见变化 | 恢复方式 | 来源 |
| --- | --- | --- | --- | --- |
| Default / Hover / Focus | 未交互 / 悬停 / 获得焦点 | 边框按中性 → Hover → 品牌焦点色变化；尺寸不变 | 移出或失焦恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Filled / Clearable | 存在输入值 | 显示值；可清空场景在 Hover/Focus 显示清除图标 | 清空后恢复占位并保留规范要求的焦点 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Error / Disabled | 校验失败 / 禁用 | 错误使用错误边框与提示；禁用同步降低背景、文字和图标强调 | 修正或解除禁用后恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-INPUT-01` | 基础用法 | 空输入框与占位提示 | 用于单行文本录入，占位文案不能替代字段标签 |
| `SCN-INPUT-02` | 禁用状态 | 灰色背景的不可编辑输入框 | 保留已有值的可读性，不显示可输入光标 |
| `SCN-INPUT-03` | 可清空 | 输入中状态 + 右侧清除图标 | 仅在存在内容时显示清除入口，点击后保留输入焦点 |
| `SCN-INPUT-04` | 密码框 | 同行展示密文状态与 `666888` 明文状态，各带对应眼睛图标 | 图标切换可见性，不改变实际字段值；实现时不得把两种状态缩减为一个控件 |
| `SCN-INPUT-05` | 带 Icon 的输入框 | 两列两行：左侧搜索图标、右侧日历图标，以及二者的聚焦态 | 图标可作语义提示；聚焦行使用品牌色边框，可点击图标必须提供独立交互状态 |
| `SCN-INPUT-06` | 文本域 | 多行输入框 | 高度按行数扩展，右下角可提供尺寸拖拽能力 |
| `SCN-INPUT-07` | 复合型输入框 | 纵向分别展示前置“文案”和后置“文案” | 用于单位、协议或固定前后缀；固定区与输入区使用分隔线，不得合并为同时含前后缀的单个控件 |
| `SCN-INPUT-08` | 尺寸 | Large、Default、Small | 分别为 `40px / 32px / 24px`，同一区域不混用 |
| `SCN-INPUT-09` | 带输入建议 | 输入框 + `选项 1`～`选项 5` 五项建议列表，末项为品牌色选中并带勾 | 输入触发候选列表；键盘上下键移动，Enter 确认；实现结果必须包含展开面板 |
| `SCN-INPUT-10` | 输入长度限制 | 单行 `0/10`、文本域 `0/200` | 计数放在控件右侧或右下角，达到上限后阻止继续输入或明确提示 |

- 占位文本不能代替字段标签。
- 校验失败后应将焦点和错误信息关联到对应字段。
