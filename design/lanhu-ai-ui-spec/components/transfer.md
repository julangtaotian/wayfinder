## 可见实例矩阵

每个场景都必须同时渲染左右两个完整面板，不能因为数据模型真实移动而让任意一侧在初始状态中为空。标题固定为 `列表1`、`列表2`，初始计数固定为 `0/13`。

| 场景 | 每侧可见列表项 | 搜索框 | Footer | 中间按钮 |
| --- | ---: | --- | --- | --- |
| 基础用法 | `10` 条 | 无 | 无 | 两个 `40px × 32px` 品牌色图标按钮 |
| 可搜索 | `8` 条 | 两侧均有，`160px × 32px`，占位 `请输入` | 无 | 两个图标按钮 |
| 有 Footer 栏 | `8` 条 | 无 | 两侧均有，`40px` 高，右侧 `46px × 24px` 的 `按钮` | 两个图标按钮 |
| 搜索 + 操作 | `8` 条 | 两侧均有 | 两侧均有 | 两个图标按钮 |
| 按钮文案 | `10` 条 | 无 | 无 | 两个约 `82px × 32px` 的“图标 + 按钮”操作 |
| 按钮文案 + 搜索 | `8` 条 | 两侧均有 | 无 | 两个文字操作按钮 |
| 按钮文案 + 操作 | `8` 条 | 无 | 两侧均有 | 两个文字操作按钮 |
| 按钮文案 + 搜索 + 操作 | `8` 条 | 两侧均有 | 两侧均有 | 两个文字操作按钮 |

文字操作按钮的图标与文字顺序有方向性：左移按钮为“图标 → 按钮”，右移按钮为“按钮 → 图标”；两个按钮上下排列，间距 `8px`，整体在面板之间垂直居中。

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 源/目标面板 | 标题/计数 → 可选搜索 → 选择列表 → 可选 Footer | 两侧面板等高，内部区域顺序固定 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 移动操作区 | 左移/右移按钮，可带文字 | 位于两面板之间并垂直居中 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 列表项 | Checkbox → 标签 | 选中、禁用和筛选结果遵守 Checkbox 与文字状态 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 必要交互 UI 状态

| 状态 | 触发条件 | 可见变化 | 恢复方式 | 来源 |
| --- | --- | --- | --- | --- |
| Default / Selected | 未选择 / 勾选列表项 | 标题计数、Checkbox 和移动按钮可用性同步变化 | 取消或移动后更新 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Filtered / Empty | 输入搜索值 / 无匹配项 | 只改变当前面板列表内容，保留已有选中视觉 | 清空搜索恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Disabled action | 当前方向无可移动项 | 对应方向按钮禁用，另一方向独立判断 | 出现可移动项后恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-TRANSFER-01` | 基础用法 | 左右列表、全选、`0/13` 计数、双向图标按钮 | 先选择列表项，再点击方向按钮批量移动；标题同步选中数和总数 |
| `SCN-TRANSFER-02` | 可搜索 | 两侧面板各自带搜索框 | 搜索只过滤当前面板，不清除已选状态 |
| `SCN-TRANSFER-03` | 有 Footer 栏 | 两侧面板底部增加操作按钮 | Footer 与列表滚动区分离，适合放置面板级辅助操作 |
| `SCN-TRANSFER-04` | 搜索 + 操作 | 搜索框与 Footer 同时存在 | 面板结构依次为标题、搜索、列表、Footer |
| `SCN-TRANSFER-05` | 按钮文案 | 中间按钮显示搜索形图标 + “按钮”文字 | 左移为图标在前，右移为图标在后；方向含义不够直观或需要强调动作名称时使用 |
| `SCN-TRANSFER-06` | 按钮文案 + 搜索 | 文字方向按钮 + 两侧搜索 | 搜索结果改变时仍保留明确的移动方向 |
| `SCN-TRANSFER-07` | 按钮文案 + 操作 | 文字方向按钮 + Footer | 中间承担集合移动，Footer 承担单侧列表操作 |
| `SCN-TRANSFER-08` | 按钮文案 + 搜索 + 操作 | 搜索、文字方向按钮、Footer 全部启用 | 功能最完整但密度最高，仅用于确有三类能力的复杂场景 |

## 使用规则

- 适用于在两个集合间移动多个对象的场景。
- 保持源列表与目标列表的数量、筛选和选中状态清晰可见。
- 批量移动前后应避免丢失用户已输入的筛选条件。
