## 尺寸与样式

| 项目 | 画板规格 |
| --- | --- |
| 触发输入框 | `240px × 32px` |
| 单列面板宽度 | `180px` |
| 选项高度 | `32px` |
| 两级面板 | `360px` 宽 |
| 面板可见高度 | `400px` |
| 字号 / 行高 | `14px / 22px` |
| 边框 / 圆角 | `1px solid @component-border / 2px` |
| 选项水平内边距 | `12px` |

选项右侧箭头表示存在下一级；Hover 使用浅色背景，选中项使用品牌色文字与浅品牌背景。禁用项使用禁用文字色。多选模式在触发器中使用可关闭标签。

画板的一级列展示 `第一行`～`第十行`，展开后的末级列展示 `第一行`～`第十二行`；`400px` 高度用于完整容纳 12 个 `32px` 行和面板边界，打开时从第一行开始，不自动滚动到已选项。

## 组件结构

| 区域 | 组成与顺序 | 视觉与状态 | 来源 |
| --- | --- | --- | --- |
| 触发器 | 已选路径/占位 → 清空/展开图标 | 遵守同尺寸 Select/Input 触发器视觉 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 级联面板 | 从左到右排列层级列 | 相邻列有边界，每列宽度和行高按尺寸表 | 蓝湖标注/画板实测；未标注项按研发补充 |
| 选项 | 标签 → 可选下级箭头/选中状态 | Hover、Selected、Disabled 分别可见 | 蓝湖标注/画板实测；未标注项按研发补充 |

## 必要交互 UI 状态

| 状态 | 触发条件 | 可见变化 | 恢复方式 | 来源 |
| --- | --- | --- | --- | --- |
| Closed / Open | 点击触发器 / 完成选择或关闭 | Open 显示锚定的多列面板 | 关闭后只保留触发器和值 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Hover / Selected / Disabled | 悬停、路径选中、项禁用 | 背景、文字、箭头或标签按状态变化 | 移出、改选或解除禁用后恢复 | 蓝湖标注/画板实测；未标注项按研发补充 |
| Empty | 某层没有子项或筛选无结果 | 当前列显示规范空态，不保留旧列内容 | 选择其他路径后恢复 | 研发补充 |

## 画板场景

| 场景 ID | 场景 | 画板展示 | 说明 |
| --- | --- | --- | --- |
| `SCN-CASCADER-01` | 基础用法 | 两级并列面板、父项箭头、末级选项 | 从左到右逐级展开，最终值在触发器中显示完整路径 |
| `SCN-CASCADER-02` | 有禁用选项 | 禁用父项、禁用子项、Hover 和已选态 | 禁用父项不能展开；禁用子项不能提交；已选路径使用品牌色 |
| `SCN-CASCADER-03` | 基础多选 | 各级 Checkbox、半选、禁用、触发器标签 | 父级根据子级选择同步未选/半选/全选；触发器用标签汇总结果 |
| `SCN-CASCADER-04` | 选择任意一级选项 | 各级 Radio | 每一级都可以作为最终值，Radio 明确当前提交节点，同一路径仍保持单选 |

## 场景初始路径

| 场景 ID | 初始路径与特殊行 |
| --- | --- |
| `SCN-CASCADER-01` | 展开父级 `第十行`，选中末级 `第一行`；触发器显示完整路径 `第十行 / 第一行` |
| `SCN-CASCADER-02` | 展开父级 `第十行`，选中末级 `第六行`；一级 `第八行` 禁用，末级 `第八行 / 第十一行` 禁用 |
| `SCN-CASCADER-03` | 多选父级 `第四行` 下的末级 `第四行 / 第五行`；父级显示半选，触发器显示首个标签并折叠为 `+1` |
| `SCN-CASCADER-04` | Radio 模式展开父级 `第六行`，选中末级 `第六行`；触发器显示 `第六行 / 第六行` |

## 使用规则

- 仅在选项具有明确父子层级时使用；扁平选项使用普通选择器。
- 当前选择要完整展示路径，避免只显示末级名称导致歧义。
- 层级过深或选项过多时，应提供搜索、懒加载或业务分组。
