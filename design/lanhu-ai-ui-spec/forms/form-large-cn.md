## 尺寸与样式

| 项目 | 规范 |
| --- | --- |
| 控件高度 | `40px` |
| 主控件示例宽度 | `392px` |
| 行内输入示例宽度 | 画板实测约 `145px` |
| 字号 / 行高 | `14px / 22px` |
| 标签与控件水平间距 | 画板常用 `12px` |
| 字段纵向间距 | 画板实测约 `20px` |
| 按钮高度 | `40px` |
| 典型表单标签 / 控件 | 标签区 `68px`；控件 `392px`；字段步进约 `61px` |
| 对齐表单标签 / 控件 | 左、右对齐标签区 `78px`；控件 `382px`；内容总宽 `460px` |
| 行内字段 | 标签区分别 `54px / 68px`；两个输入均约 `146px`；字段组间距 `24px` |
| 行内按钮 | 查询、重置均为 `68px × 40px`，按钮间距 `12px` |
| 多行输入 | `52px` 高 |

大尺寸中文表单适用于信息密度较低、操作频率较高或需要强调可读性的录入页面。画板覆盖典型表单、行内表单，以及标签左对齐、右对齐、顶部对齐三种布局。

| 场景 ID | 场景 | 画板展示 | 大尺寸处理 |

| `SCN-FORM-LARGE-CN-01` | 典型表单 | 活动完整录入流程及创建/取消 | 所有输入和按钮使用 `40px`，适合低密度页面 |
| `SCN-FORM-LARGE-CN-02` | 行内表单 | 审批人、活动区域、查询、重置 | 行内输入约 `145px` 宽，按钮和控件统一为 `40px` |

## 场景精确差异

- 典型、行内、标签左对齐、标签右对齐四个场景使用 `40px` Large 控件。
- 蓝湖的“标签顶部对齐”场景是明确例外：输入、选择、日期时间和按钮实际使用 `32px` 高度，单列控件宽 `460px`；AI 做原画还原时必须服从该场景值，不能仅按文件名强制改成 `40px`。
- 标签顶部对齐场景第一行四个 Checkbox 的可见文案均为“备选项”，第二行保留“线下主题活动、单纯品牌曝光”；Radio 组标签为“顶对齐标签”。
- 标签左对齐场景保留顶部三段“选项”切换；标签右对齐的参考裁图从名称字段开始。
- 参考画板中的局部裁切不改变完整页面应有的标题、说明和字段结构。

## AI 还原约束

- 除顶部对齐例外外，Large 表单内 Input、Select、DatePicker、TimePicker 和 Button 必须统一 `40px`。
- 只使用真实组件库 Form 体系和子组件；主色 `#FF6014`、危险色 `#F53F3F`、边框 `#DCDCDC`、占位色 `#BFBFBF`。
- 日期、时间、Select 图标使用组件库等义图标或[组件图标资产清单](../assets/icons/manifest.md)中的替换资产，不得绘制无来源图标。
- 当容器不能容纳 `460px` 表单与标签时整体切换为单列，不得出现横向滚动或操作按钮越界。

## 使用规则

- 只在整个表单或完整操作区需要大尺寸时使用，避免局部混用。
- 适合触控环境、长文本输入和需要更大点击热区的场景。
- 字段分组、帮助文案和错误提示仍遵循默认尺寸表单的结构规则。
