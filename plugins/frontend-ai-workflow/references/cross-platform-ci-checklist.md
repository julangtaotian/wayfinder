# 跨平台 CI 防回归清单

本清单用于修改 CI、路径、临时目录、子进程、包管理器入口、环境变量或机器可读诊断的变更。它把跨平台差异作为显式设计输入，不要求无差别执行全部检查；命中的风险项必须进入变更资料、确定性回归和验证证据。

## 风险标记

在需求、设计、任务或验证记录中写明：

- 跨平台高风险：是。
- 命中项：CI / 路径 / 临时目录 / 子进程 / 包管理器入口 / 环境变量 / 机器可读诊断。
- 受影响平台：以仓库真实 CI 矩阵为准，不根据本机推测。
- 对应回归：测试文件、稳定定位和聚焦命令。
- 外部证据：运行 URL、精确提交 SHA、矩阵任务及状态；尚未运行时保持待执行。

没有命中项时可以记录“跨平台高风险：否”，但必须能由受影响文件和调用链解释，不能因本地测试通过而直接判定为否。

## 实施检查

### 文件路径

- 使用平台路径 API 进行拼接、相对化和规范化，不把 `/` 当作所有平台的唯一分隔符。
- Git、子进程、`cwd`、`realpath`、`path.join` 等不同来源的路径用于相等、集合、前缀或去重判断时，实际值和期望值必须调用同一个规范化函数；禁止一侧规范化、一侧保留原值，也禁止直接严格比较原始字符串。
- 外部工具在 Windows 也可能返回 `/`，不得根据 `process.platform` 猜测输出分隔符。在当前平台解析外平台样本时显式选择 `path.win32` 或 `path.posix`，不能让宿主平台默认 `path` 语义代替目标平台。
- Windows 确定性回归至少覆盖 Git 风格 `D:/workspace` 与 Node 风格 `D:\\workspace` 的双侧规范化、盘符表现和尾部分隔符；需要验证原始诊断时，再分别保留 POSIX `/` 与 Windows `\` 样本。
- 不用包含绝对工作区、盘符或临时目录的整段消息作为唯一断言。

### 子进程与包管理器入口

- Windows 不直接启动 `npm.cmd`、`npx.cmd` 等包装器；优先使用当前 Node 进程执行从环境或已安装包解析出的 JavaScript CLI 入口。
- 不为兼容而默认启用 shell；必须使用 shell 时记录原因，并验证空格、引号、非 ASCII 路径和参数边界。
- 子进程失败必须保留真实退出码和标准错误，不能把启动失败、零测试发现或业务断言失败合并成“测试失败”。

### 临时目录、fixture 与 Git

- 验证产物进入仓库规则指定的有界目录，只清理本次明确创建的子目录。
- 仓库内临时 fixture 不得继承父仓库的 Git 根和忽略规则；按场景初始化独立仓库，或使用 `GIT_CEILING_DIRECTORIES` 阻断向上发现。
- 成功、阶段失败和进程异常都必须进入清理路径；清理本身失败时保留原始失败并单独报告清理问题。

### 环境变量

- 使用平台路径分隔符处理路径列表，不硬编码 `:` 或 `;`。
- 只注入当前验证需要的环境变量，不覆盖用户环境中的无关值，不复用 `HOME` 等系统关键变量承载任务配置。
- 对 `TMPDIR`、`TMP`、`TEMP` 等平台别名保持一致边界，并验证子进程实际继承的环境。

### 机器可读诊断

- 先解析 JSON 或其他结构化输出，优先断言稳定的 `code`、`target`、`status`、计数和退出状态。
- 中文或英文人类消息只验证必要语义；平台路径、工具前缀和换行差异不得成为唯一成功条件。
- 当结构字段不足以定位问题时，先补稳定机器字段，再扩展测试，避免持续堆叠平台相关正则。

### CI 工作流

- CI 使用项目声明的单一、自包含验证入口，准备、验证和清理生命周期在本地与 runner 上保持一致。
- runner 矩阵、运行时版本、平台打包和清理步骤都必须从真实工作流读取，不根据历史运行或文档猜测。
- 聚焦回归证明具体差异，全量验证证明共享链未回退，真实矩阵证明外部平台；三类证据不能相互替代。

## 交付证据

按以下层级分别记录，不合并结论：

1. 聚焦回归：命中的平台差异已被确定性测试覆盖。
2. 本地统一验证：共享入口、结构检查、清理和相关发布资产通过。
3. 真实 CI 矩阵：仓库声明的全部平台任务在同一提交上成功。

只有第 3 层实际完成后，才可把外部跨平台证据标为通过。无网络、无权限或尚未提交时，保留待执行并明确当前只完成了哪些本地证据。

## 失败复盘

Actions 失败后在当前变更验证记录中追加：失败平台、失败步骤、稳定错误字段、根因、为何本地未发现、补充的回归定位和复跑 URL。修复前先检查既有测试是否只覆盖当前系统、完整错误文案或父仓库偶然状态；修复后不得删除能稳定复现根因的回归。
