# Bundled Playwright Runtime

This source runtime pins Playwright 1.62.1, PNGJS 7.0.0, and pixelmatch 7.1.0 once in the shared `node_modules` tree. It also keeps the lockfile, licenses, five platform metadata records, and the shared integrity manifest.

The supported packs are `darwin-arm64`, `darwin-x64`, `linux-x64`, `linux-arm64`, and `win32-x64`. The repository does not keep their Chromium or FFmpeg binaries. A prepared installable distribution contains exactly one native pack, its licenses and generated integrity manifest, plus the complete shared runtime. Target frontend repositories do not install or resolve these packages.

Downloads are allowed only through the preview-first platform preparation flow while building or updating the plugin. It writes only to a bounded staging directory outside the source runtime, uses the fixed Playwright CLI, and cleans the current stage on failure. Linux ARM64 obtains the missing Chromium license from a bounded, same-version Linux x64 official download during preparation. Runtime inspection, smoke tests, adapters, installed plugins, and unified UI review must never download browsers or fall back to an end-user cache.

Use the preview-first `prepare-platform-marketplace.mjs` command to build an installable platform marketplace. It writes only with explicit `--write`, rejects non-native, existing, or unsafe output paths, rebuilds integrity, and enforces platform budgets with headroom. Chromium, FFmpeg, licenses, the shared runtime, and integrity manifests are mandatory. Linux ARM64 debug symbols are removed only from the native staged copy and the packaged browser must still pass a real smoke test. A verified marketplace may be copied for offline installation; rollback restores the prior verified output or source commit without rewriting history.
